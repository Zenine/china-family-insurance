# 06 核保策略

结论：有健康异常的成员只做智能核保，多家产品同时试，挑结论最好的一家投；不进人工核保，因为人工核保的结论会留档；告知按问卷问到的逐条如实回答，不扩大也不遗漏。

## 几个词

- **健康告知**：投保页上的一组问题（是否住院、是否手术、是否患有某类疾病、是否有复查建议等）。全部回答「否」才能直接投保；有一条「是」就要进入核保。
- **智能核保**：在线问答式核保。按疾病逐层选择具体情况（分级、确诊时间、用药、复查结果），系统当场给结论。
- **人工核保**：上传病历、体检报告，由保险公司核保人员审核，几天到几周出结论。
- **核保结论**：标准体（正常承保）、加费（保费上浮）、除外（某类疾病不赔，其余照保）、延期（暂不承保，过一段时间再申请）、拒保。

## 判断规则

### 投保前准备

1. 读成员档案的健康状况与原件：体检报告结论页、门诊病历、出院小结、复查结果（`references/16-资料收集与问诊.md`）。
2. 每个异常项摘出核保会问的四件事：诊断名称与分级、确诊或手术日期、目前治疗与控制情况、医生是否建议复查。
3. 列出要投的险种。意外险、惠民保不看健康，直接投；寿险、重疾、医疗、防癌医疗要过健康告知。

### 如实告知

1. **问什么答什么**：告知范围以问卷问到的为限，问卷没问的不需要主动说；问到的必须答，日期、次数、结论照原件。
2. **逐条对照原件**：手术做了两次就答两次；出院小结写「建议复查」，问卷问「是否有医生建议的检查或复查尚未完成」时要答。
3. **口头提过、没有书面记录的情况**：看问卷措辞。问「是否被诊断为」「是否有检查异常」，没有诊断和检查单就答否；问「医生是否曾提出任何异常」这类宽口径时，如实提及。
4. **不为了过核保改措辞**。告知不实，出险时保险公司可以拒赔、解除合同，而那正是最需要钱的时候。
5. 投保人豁免要求投保人也回答健康告知，同样如实（`references/09-投保人豁免.md`）。

### 智能核保怎么做

1. **多家并行**：同一险种挑 3–5 款告知宽严不同的产品，同时做智能核保。不同公司对同一种病的结论差别很大，有的拒保，有的加费，有的除外。
2. **先预核**：部分平台可以先答问卷看结论、不填身份信息；能预核的先预核。
3. **结论取舍**：标准体 > 除外（除外部位与这个人的风险无关时）> 加费 > 除外（除外的正是最可能出事的部位）> 延期 / 拒保。加费和除外都可以接受，按买到的保额在矩阵里打档（`references/04-缺口矩阵.md`）。
4. **智能核保提示「转人工」时，换下一款产品**，不进入人工核保流程。
5. **全部拒保**：标「核保受限」，走替代路径（`references/07-慢病与核保受限人群.md`），并在 TODO 写明什么条件满足后再试（指标控制达标满多久、复查结果稳定）。

### 为什么不进人工核保

- 人工核保的结论会在保险公司留档，至少影响以后在同一家公司再投保。
- 很多产品的健康告知会问「是否曾被保险公司拒保、延期、加费或附加条件承保」。人工核保被延期或拒保后，这一问以后都要答「是」，可选的产品变少。
- 智能核保多数不留记录（以平台说明为准），可以多家试，试错成本低。
- 只预核、没有正式提交投保的，不算投保记录；正式提交后被拒保或延期的，以后遇到「是否曾被拒保 / 延期」按问卷原文如实回答。

### 时间安排

- 体检、复查后拿到新结果，再做核保；结果有利（指标好转、结节稳定）时，带着新结果试。
- 有投保窗口（满周岁、年龄上限）的，核保要在窗口前做完，留出换产品的时间。
- 核保结论（日期、险种、结论、除外或加费内容）写进成员档案「健康状况」或「已有保单」，以后不再重复试同一款。

## 示例

示例家庭的爸爸（`examples/demo-family/members/self.md`）：高血压 2 级，两种降压药控制，近半年血压约 135/85 mmHg；甲状腺结节 TI-RADS 3 类，每年复查稳定。

- 准备：近半年血压记录、2026-03 体检报告结论页、甲状腺超声复查单。
- 定期寿险：现有示例定寿 A 是加费 50% 承保。这次加保 170–200 万（合计 370–400 万），同样挑 3–5 款同时智能核保，给出加费的选加费最少的一款，提示转人工的跳过。
- 重疾：甲状腺结节导致多家除外甲状腺相关疾病，示例重疾 B 除外承保，按 30 万打「一般」。
- 百万医疗：2025 年进了人工核保被拒，这条记录让他以后投保时遇到「是否曾被拒保」都要答「是」。这次改投防癌医疗（多数不问高血压），血压连续达标满 1 年后，带复查结果多家智能核保重试百万医疗。

## 常见错误

| 错误 | 正确做法 |
| --- | --- |
| 只试一家，被拒就放弃 | 3–5 家智能核保并行，挑最好的结论 |
| 智能核保提示转人工就提交病历 | 换下一款产品，不进人工核保 |
| 告知时把两次手术写成一次、漏写复查建议 | 日期、次数、医嘱照原件答 |
| 问卷没问的病史也主动写上 | 只答问到的，问到的不遗漏 |
| 为了过核保换说法 | 如实告知，否则理赔时被拒 |
| 加费或除外就不买 | 和这个人的风险无关的除外、能承受的加费都值得买 |
| 核保结论不记录，下次又试同一款 | 结论写进成员档案 |
