# 14 隐私分级与资料原件

结论：家庭保险库含全家的健康与财务信息，整个库必须私有；库内再分四级——总览明文、库正文、原件、不入库——每条信息写进去之前先判断它属于哪一级。原件能不能随库提交，取决于库会不会公开或同步到别处。

## 四级

| 级别 | 放哪里 | 内容 |
| --- | --- | --- |
| 一级：总览明文 | `site/index.html` 明文区 | 成员称呼、五险种档位（「核保受限」按「不足」显示）、生成日期 |
| 二级：库正文 | `members/`、`policies/`、`analysis/`、`recommendations/`、`TODO.md`、`CHANGELOG.md` | 出生年月、健康结论、核保结论、收入与负债、保单字段（保单号只写末 4 位）、保费、配置建议 |
| 三级：原件与口令 | 原件：库只存本机或私有仓库时放 `policies/<代号>/`、`members/<代号>/`，否则放 `.private/`；口令与明细 JSON 一律放 `.private/`（git 忽略，权限 700） | 保单 PDF 与截图、体检报告、病历与出院小结、证件扫描件、总览页口令、自行整理的明细 JSON |
| 四级：不入库 | 任何地方都不写 | 账号密码、支付密码、验证码、完整银行卡号；与本家庭无关的第三方的完整个人信息 |

规则：

1. **库本身私有**：只放本机或私有仓库。私有仓库也不加无关协作者；仓库若开启了网页发布，按 `references/15-总览页与加密.md` 判断风险。
2. **正文只写结论**：病历写诊断与结论，证件只写存放位置，保单号写末 4 位。证件信息确需留档时只写出生日期与证件号末 4 位。
3. **原件放哪里看库的去向**：库只存本机或私有仓库、不会公开也不会同步到别处时，原件可以随库提交，保单原件放 `policies/<代号>/`，体检报告、病历、证件放 `members/<代号>/`。库可能转为公开、会同步到网盘、或要交给别人维护时，原件只放 `.private/`（可以平放，也可以按代号分目录）。同一个库用同一种放法，写进库内 `AGENTS.md`。
4. **文件名不带真实姓名**：原件改名为「代号-类型-日期」，如 `.private/self-体检-2026.pdf`；台账里引用改名后的文件名。
5. **总览明文只放称呼与档位**：金额、产品名、公司、日期、电话、备注、「核保受限」都只进加密明细；明细也不放完整保单号、证件号、病历、原件链接。明文区出现「年保费合计」「某人意外为 0」这类信息，加上页面地址里的用户名，就能认出是哪一家。
6. **提交信息泛化**：Git 提交信息写「更新 spouse 医疗台账」，不写保单号、病名、金额。
7. **对外导出前扫描**：把库里的任何内容发给库外的人（保险顾问、亲戚、其他 AI 服务）之前，只导出需要的那几段，并运行：

   ```
   node scripts/privacy-scan.mjs <要导出的目录>
   ```

   命中证件号、手机号、长保单号就改掉再发。可以用 `--blacklist <文件>` 加一份自家的敏感词清单（真名、产品与金额组合），清单本身放 `.private/`。
8. **AI 读到的内容会进入会话记录**：让 AI 读原件提取字段时，原件内容会出现在该 AI 工具的会话记录里。不愿意的，用户自己摘录后口述给 AI。
9. **TODO 与 CHANGELOG 同样受限**：不写完整保单号、证件号、车牌、化验数值。

## 示例

示例家庭随本 skill 公开发布，属于「可能公开」的库，所以体检报告都放在 `.private/`，档案只写文件名，如 `examples/demo-family/members/self.md` 的「体检报告：`.private/self-体检-2026.pdf`」；健康状况写诊断、控制情况与结节分级，不抄整份报告数值。

示例家庭爸爸的医疗在矩阵里是「核保受限」，总览页明文区显示「不足」，输入口令后才看到「核保受限」和高血压相关备注。示例家庭的 `.gitignore`（`examples/demo-family/.gitignore`）只有一行 `.private/`。

## 常见错误

| 错误 | 正确做法 |
| --- | --- |
| 可能公开或会同步的库里提交了体检报告 | 放 `.private/`，档案写文件名 |
| 原件文件名带真实姓名 | 改为「代号-类型-日期」 |
| 明文总览放保费合计或「为 0」 | 明文只放称呼与档位 |
| 把整个库发给保险顾问看 | 只导出需要的段落，导出前扫描 |
| 提交信息里写病名和保单号 | 泛化为「更新 <代号> <险种> 台账」 |
| 账号密码记在 TODO 里方便续费 | 不入库，用密码管理器 |
