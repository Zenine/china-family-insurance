# 07 慢病与核保受限人群

结论：有慢病或结节的人，定期寿险常常可以加费承保，重疾险多数拒保或除外，百万医疗常被拒；先把定期寿险买足，医疗用防癌医疗兜底，重疾缺口用专项储备替代，指标稳定后每年重试。

## 判断规则

### 各险种对慢病的松紧

| 险种 | 常见结论 | 原因 |
| --- | --- | --- |
| 定期寿险 | 控制良好时多为标准体或加费 | 只赔身故、全残，慢病对短期身故率影响有限，用加费定价 |
| 重疾险 | 拒保、延期，或除外相关器官 | 慢病会直接推高相关重疾（心脑血管、肾病、相关癌症）发生率 |
| 百万医疗 / 长期医疗 | 拒保或除外 | 慢病带来持续住院与并发症费用 |
| 防癌医疗 / 防癌险 | 多数只问癌症相关问题，三高等常可投 | 只保癌症 |
| 意外险、惠民保 | 不看健康 | 惠民保对既往症通常不赔或降低报销比例，看条款 |

### 常见类别与核保关注点

具体结论以产品问卷和智能核保为准，下表是各类病情被问到的重点：

| 类别 | 核保关注 | 资料要备 |
| --- | --- | --- |
| 高血压 | 分级（1 / 2 / 3 级）、确诊年限、用药种类、近期血压、有无心脑肾并发症 | 近 3–6 个月血压记录、体检结论 |
| 糖尿病 | 分型、确诊年龄、用药或胰岛素、糖化血红蛋白、有无眼底 / 肾 / 神经并发症 | 近期糖化血红蛋白、空腹血糖 |
| 甲状腺结节 | TI-RADS 分级、大小、是否穿刺、复查是否稳定 | 最近两次超声报告 |
| 乳腺结节、肺结节 | BI-RADS 分级或结节大小与密度、随访是否稳定 | 最近两次影像报告 |
| 乙肝 | 携带者还是肝炎、肝功能是否正常、病毒载量、是否抗病毒治疗、有无肝纤维化 | 肝功能、乙肝五项、病毒载量、肝脏超声 |
| 高血脂、肥胖 | 血脂数值、BMI、是否合并其他代谢异常 | 体检结论、血脂化验 |

规律：分级越低、确诊越久且稳定、无并发症、复查记录完整，结论越好。甲状腺结节 2 类及以下多为标准体，3 类常见除外或加费，4 类及以上常见延期到明确良性；其他结节按各自分级同理。

### 补齐顺序

1. **定期寿险先买足**：慢病人群最容易拿到的长期保障，加费也值得。保额按 `references/04-缺口矩阵.md` 的公式算，不因为加费而降保额。
2. **医疗用防癌医疗兜底**：百万医疗被拒时，先投不问该慢病的防癌医疗，再加惠民保；单位补充医疗离职即失效，不能当长期方案。
3. **重疾能买就买，除外也买**：除外的器官以外仍有保障。完全买不到时，标「核保受限」。
4. **专项储备替代重疾**：每年把原本准备用于重疾的保费（或更多）存进一个单独账户，不挪作他用，目标是攒到重疾应有保额（30–50 万）。储备未攒够前，这段缺口由定期寿险（身故）和防癌医疗（癌症费用）部分覆盖。
5. **慢病专属产品**：市面上有针对糖尿病、高血压等人群的专属重疾或医疗产品，条款与在售情况变化快；用户要了解时按 `references/17-推荐方案输出.md` 的方法当场查，核对保障范围是否把该慢病的并发症排除在外。
6. **每年重试**：每次复查后，指标稳定或好转的，带新结果再做一轮智能核保（`references/06-核保策略.md`）。TODO 写明重试条件和时间。

### 在矩阵里怎么标

- 加费或除外后买到了：按保额打档，括号注明「加费承保」「除外 XX」。
- 被拒后只剩惠民保、单位团险或防癌医疗：标「核保受限」，括号写替代路径。
- 「核保受限」只进加密明细，总览页明文按「不足」显示（`references/15-总览页与加密.md`）。

## 示例

示例家庭的爸爸，高血压 2 级 + 甲状腺结节 3 类：

| 险种 | 结论 | 处理 |
| --- | --- | --- |
| 定期寿险 | 加费 50% 承保 200 万 | 应保额 362 万，再加保 170–200 万（合计 370–400 万），同样接受加费 |
| 重疾 | 除外甲状腺相关疾病，30 万 | 结节复查稳定后另投 20 万补到 50 万；买不到时用专项储备补差额 |
| 百万医疗 | 2025 年被拒 | 投不问高血压的防癌医疗 + 惠民保；血压连续达标满 1 年后重试 |
| 意外 | 不看健康 | 补个人意外，替代离职即失效的团险 |

## 常见错误

| 错误 | 正确做法 |
| --- | --- |
| 有慢病就认为什么都买不了 | 定寿、防癌医疗、意外、惠民保大多能买 |
| 加费了就把寿险保额砍小 | 保额按责任算，加费照买 |
| 被拒后不再尝试 | 指标稳定后每年重试 |
| 把惠民保当成慢病人群的医疗险主力 | 惠民保对既往症常不赔，只作兜底；先配防癌医疗 |
| 专项储备挪作日常开销 | 单独账户，只用于大病 |
| 「核保受限」写进明文总览 | 只进加密明细 |
