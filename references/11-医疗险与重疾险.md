# 11 医疗险与重疾险

结论：医疗险是报销，花多少报多少，管医院账单；重疾险是给付，确诊就按保额一次给钱，管收入损失和康复开销；两者管的是不同的钱，每个成年人都要有，不能互相替代。

## 判断规则

### 两者的区别

| | 医疗险（百万医疗、长期医疗、防癌医疗） | 重疾险 |
| --- | --- | --- |
| 怎么赔 | 报销：凭发票，扣掉社保已报和免赔额后按比例报 | 给付：确诊合同约定的疾病或达到约定状态，一次给保额 |
| 管什么钱 | 住院、手术、特药等医疗费 | 停工期间的收入、家人陪护、康复、营养、房贷月供 |
| 多份能否叠加 | 不能重复报销，总额不超过实际花费 | 多份可以分别给付 |
| 期限 | 多为一年期；长期医疗保证续保 15–20 年 | 定期或终身，保费锁定 |
| 健康要求 | 严，常因慢病拒保或除外；防癌医疗例外，只问癌症相关问题，慢病人群常可投 | 严，常因慢病拒保或除外 |
| 保费 | 每年几百元起，随年龄上涨 | 每年几千元，交费期内不变 |

### 为什么都要

- 只有医疗险：住院费报了，但治疗和康复期一两年不能工作，收入断了，房贷照还。
- 只有重疾险：保额可能被几十万的医疗费吃掉，留给生活的钱不够；不在重疾清单里的大病（如严重意外后的长期住院）不赔。
- 所以每个成年人都要「医疗险 + 重疾险」：医疗险兜医院账单，重疾险兜家庭现金流。孩子同样两者都配，重疾险在孩子身上主要补父母停工陪护的收入损失。

### 医疗险看什么

1. **保证续保年限**：最重要。一年期产品停售或因理赔不能续，就断了；保证续保 15–20 年的才算长期保障（`references/04-缺口矩阵.md` 医疗阈值）。
2. **免赔额**：百万医疗常见 1 万元年免赔，同一家庭多人共用免赔额的更好。
3. **报销范围**：社保外费用是否报、外购特药与院外药清单、质子重离子。
4. **报销顺序**：社保 → 惠民保或单位补充医疗 → 百万医疗；出险后先走社保结算。
5. 惠民保、单位团险是补充，不替代个人医疗险（`references/18-常见问题.md`）。

### 重疾险看什么

1. **保额**：成人 50 万起为「充分」，30–50 万「一般」（`references/04-缺口矩阵.md` 重疾阈值）；保额大致按 3–5 年家庭开销或本人收入估。
2. **保障期**：成人至 70 岁或终身，孩子保到能自主投保（`references/10-定期与终身.md`）。
3. **高发疾病的定义**：恶性肿瘤、急性心梗、脑中风后遗症等以行业统一定义为准，各家差别主要在轻症、中症和少儿特疾。
4. **中症、轻症、多次赔付**：加分项，不影响矩阵档位。

### 核保受限时

医疗险被拒先补防癌医疗，重疾被拒用专项储备替代（`references/07-慢病与核保受限人群.md`）。

## 示例

示例家庭：

- 妈妈：示例百万医疗 F（保证续保 20 年）+ 示例重疾 E 50 万至 70 岁，两项都「充分」。
- 爸爸：重疾 30 万（甲状腺相关除外）是「一般」；百万医疗被拒，医疗只剩单位补充医疗和惠民保，矩阵标「核保受限」。如果爸爸确诊重疾，30 万给付先补停工期间的收入和房贷月供，医疗费主要靠职工医保和单位补充医疗——离职后这一层就没了，所以下一步先补防癌医疗。
- 妹妹：重疾 50 万已投，医疗是空白；居民医保生效后投少儿医疗，两者才配齐。

## 常见错误

| 错误 | 正确做法 |
| --- | --- |
| 有了百万医疗就不买重疾 | 医疗险不补收入损失，重疾也要 |
| 有了重疾就不买医疗险 | 医疗费会吃掉重疾保额，两者都要 |
| 买两份百万医疗想多报一份 | 报销型不能重复报，选一份保证续保的 |
| 医疗险只比保额（几百万）不比续保 | 先看保证续保年限 |
| 惠民保当成百万医疗 | 惠民保免赔高、既往症常不赔，只作补充 |
| 孩子只配医疗不配重疾 | 重疾补父母陪护的收入损失 |
