# 04 缺口矩阵

结论：缺口矩阵是「成员 × 五险种」的表，每格取六个档位之一；按下面的阈值打分，资料不够就标「缺资料」，因健康原因买不到就标「核保受限」，两者都不算「不足」。

## 输入与顺序

1. 先读 `TODO.md`：里面列着已知但还没录入的保单，这些格子标「缺资料」，不能当成没有保障。
2. 读全部 `members/*.md`：年龄、职业类别、家庭角色、收入、负债、健康与核保结论、已有保单勾选。
3. 逐人读 `policies/<代号>/*.md`：险种、保额、保障期限与续保条件、等待期、免赔额、特别约定。
4. 按下面的阈值逐格打档，写进 `analysis/gap_matrix.md`（模板 `templates/gap_matrix.md`）。
5. 写「关键缺口」「观察」「未纳入风险」三段。
6. 矩阵改完重建总览页（`references/15-总览页与加密.md`）。

## 六个档位

| 档位 | 含义 |
| --- | --- |
| 充分 | 达到下表「充分」阈值 |
| 一般 | 达到「一般」阈值，或保额够但保障期、续保条件偏弱 |
| 不足 | 低于「一般」阈值，或该成员需要这个险种但完全没有 |
| 缺资料 | 资料不够判断：保单未录入、保单在别人手上、医保参保待确认、收入或目标金额未知 |
| 不适用 | 这个成员不需要这个险种：子女寿险、退休老人寿险与年金、老人新配重疾保费倒挂且已用防癌医疗替代、未入托的婴儿意外险 |
| 核保受限 | 需要这个险种，但因健康原因被拒保、延期或没有可投产品；手上只剩不看健康的兜底（单位团险、惠民保）或替代路径（防癌医疗、专项储备） |

- **缺资料不等于不足**。没看到保单就打「不足」，会让用户重复投保。
- **「没有」要用户确认过才算**。某人某险种没有录入保单时，先问一次全家：「除了已经录入的，家里还有别的保单吗？包括单位团险、信用卡或支付平台送的、学校统一投保的。」用户确认没有，才按「完全没有」打「不足」；还没确认的格子标「缺资料」，括号写「其他保单待确认」。用户确认后，在该成员 `members/<代号>.md` 的「备注」加一行「已确认除已录入的保单外没有其他保单（YYYY-MM-DD）」；矩阵里打「不足」的「没有」格，对应成员档案里都应有这一行，以后不再重复问。
- **核保受限不计入不足**。它说明问题不在钱或意愿，而在健康；格子里写替代路径（防癌医疗、专项储备等）。加费或除外后仍买到了的，不标核保受限，按买到的保额打档，在括号里注明「加费承保」「除外 XX」。被拒后只剩单位团险、惠民保这类不看健康的保障时，仍标「核保受限」，不按下面医疗阈值里的「一般」打。
- 「核保受限」等于间接披露健康状况：总览页明文区按「不足」显示，原档位只在加密明细里出现。

## 阈值

### 寿险

- 谁需要：承担家庭现金流的人（家庭角色为主要收入来源，或有收入且共同承担负债）。子女、退休老人一般「不适用」。
- 应保额 ≈ 未还清负债 + 子女至 22 岁的支出累计 + 配偶 10 年生活费。不用「年收入 × 10」这类公式。
- **备用算法**：拿不到每个孩子和配偶分开的支出、只知道家庭年支出合计时，按「家庭年支出 × 最小子女到 22 岁的年数 + 未还清负债」估算；没有子女的，年数取 10。两种情况的结果都是粗估，矩阵格子和推荐方案里都标「粗估」。家庭年支出也不知道时标「缺资料」，不按收入倒推。
- 充分：实际保额 ≥ 应保额；一般：50%–100%；不足：< 50% 或为 0。
- **主要收入者寿险为 0 时，在关键缺口里固定排第一**。
- 单位团险的身故责任只在在职期间有效，计入时档位最高到「一般」，格里注明「离职即失效」。

### 重疾

- 谁需要：全体成员。年龄较大（通常 55 岁以上）时先算保费总额与保额比：总保费接近或超过保额就是保费倒挂，改用防癌医疗，标「不适用」并写替代方式。
- 充分：保额 ≥ 50 万，且保障期覆盖到子女能自主投保、成人到退休。
- 一般：保额 30–50 万；或保额够但保障期偏短。
- 不足：保额 < 30 万或没有。
- 中症、轻症、多次赔付只在括号里说明，不影响档位。
- 学平险、团险附带的小额重疾（几万元）不能替代重疾险，按实际保额打档。

### 医疗

- 分三层：社保（职工 / 居民医保）→ 百万医疗或长期医疗 → 中高端医疗。惠民保是社保之上的补充，不替代百万医疗。
- 充分：有社保 + 保证续保 ≥ 15 年的百万医疗或长期医疗。
- 一般：有社保 + 一年期或不保证续保的百万医疗；或只有防癌医疗 + 惠民保；或没有被拒保、只是还没投个人医疗险，暂时依赖单位补充医疗（离职即失效）。
- 不足：只有社保，或连社保都没有。
- 重点看续保条件，不看当年保额。

### 意外

- 成人：身故保额 ≈ 1 年家庭开销，意外医疗 0 免赔、社保外可报为佳。
- 子女与老人：看意外医疗与伤残，身故保额不作主判据。不满 1 岁、在家照看、未入托的婴儿意外风险主要在家庭看护，可标「不适用」，入托前再配。未成年人的身故保额有合计上限，按下文「未成年人身故保额合计核对」算。
- 充分：成人保额 ≥ 1 年家庭开销且含意外医疗；子女（入托以后）与老人有含意外医疗的意外险。
- 一般：保额够但意外医疗责任差；或只有单位团险（离职即失效）。
- 不足：没有，或成人保额 < 1 年家庭开销。
- 职业类别 4 类及以上通用产品不保，在括号里注明，选品另找。

### 年金 / 教育金

- 谁需要：主要收入者的退休补充（目标替代率 40%–50% 倒推）；子女教育金（需要目标金额与年份）。
- 充分：现值 ≥ 目标 80%；一般：50%–80%；不足：< 50% 或有目标无规划。
- 没有目标金额、企业年金或养老金情况不明时标「缺资料」。
- 年金与增额寿的收益受预定利率上限约束，监管已多次下调这个上限；估现值时按投保页的利益演示（保证部分）算，不按股票收益率估。

### 未成年人身故保额合计核对

父母给未满 18 周岁的子女投保，所有保单约定的身故保险金合计有上限：不满 10 周岁不超过 20 万元，已满 10 周岁未满 18 周岁不超过 50 万元。每份合同里的三项不计入：已交保费或身故时的现金价值（投连、万能险为账户价值）、航空意外身故保额、重大自然灾害意外身故保额。出处：《中国保监会关于父母为其未成年子女投保以死亡为给付保险金条件人身保险有关问题的通知》（保监发〔2015〕90号）第一条、第二条，核对日期 2026-11-21。

每次给未成年成员录入或推荐含身故责任的保单时核对一次：

1. 列出该成员全部保单：寿险、重疾（含身故责任的）、意外险、学平险等以父母为投保人的都算。
2. 逐份读台账 `身故保额`。身故只退已交保费或现金价值的记 0；意外险只算普通意外身故，航空意外、重大自然灾害意外的额外部分不加；写「待补」的先补，合计写「待补」。
3. 加总后和当前年龄的上限比较。孩子满 10 周岁后上限变 50 万，按核对当天的周岁算。
4. 超出时，矩阵该成员意外格括号里写「身故保额合计 X 万，超出上限 Y 万，超出部分赔不了」；推荐方案里不再加身故责任，新增意外险以意外医疗和伤残为主，并写明超出部分赔不了。

### 子女长期险的投保人豁免

不默认要求。投保人豁免保的是投保人：投保人过不了豁免的健康告知时，不为了加豁免而换方案，断保风险由投保人自己的寿险兜底。判断方法见 `references/09-投保人豁免.md`。

## 格子写法

- 每格以档位词开头，后面括号写依据：`一般（示例重疾 B 30 万，甲状腺相关除外）`。总览页只认开头的档位词，认不出的按「缺资料」显示。
- 需要强调的档位可加粗：`**不足**（骨质疏松，未配老年意外）`。
- 每行第一列以成员代号开头，后跟称呼和年龄：`self 爸爸（42）`。
- 不编保额数字；不在矩阵里点名推荐产品（推荐见 `references/17-推荐方案输出.md`）。

## 关键缺口、观察、未纳入风险

- **关键缺口**：按优先级列 3–5 条，每条写成员、险种、现状与差额。排序：主要收入者的寿险与重疾 → 子女 → 老人（详见 `references/05-配置原则.md`）；同一层里，无健康告知、保费低、可以马上投的排前面。
- **观察**：续保风险（一年期产品停售）、团险离职即失效、核保受限成员每年复查后重试、资料缺口。
- **未纳入风险**：长期护理、财产险、责任险，以及现金储备、遗嘱、受益人安排等非保险工具。

## 示例

示例家庭的矩阵在 `examples/demo-family/analysis/gap_matrix.md`，六个档位都用到了。

**爸爸寿险，按本章公式算**（数字来自 `examples/demo-family/members/self.md`：房贷余额 200 万；每个孩子年支出约 3 万；妈妈个人生活费约 6 万 / 年；哥哥 10 岁、妹妹 0 岁）：

```
未还负债                     200 万
哥哥到 22 岁：(22 − 10) × 3 万 =  36 万
妹妹到 22 岁：(22 − 0) × 3 万  =  66 万
妈妈 10 年生活费：10 × 6 万    =  60 万
应保额合计                   362 万
现有：示例定寿 A 200 万 → 200 ÷ 362 ≈ 55%
```

55% 落在 50%–100%，档位「一般」，差额约 162 万。单位团险只有意外身故，不计入寿险。

假如只知道家庭年支出约 20 万、不知道分项，用备用算法：20 万 × (22 − 0) 年 + 200 万 = 640 万，标「粗估」。备用算法把爸爸自己的支出也算进去，结果通常偏高；拿到分项后改用主公式。

**哥哥身故保额合计核对**（10 岁，上限 50 万）：示例少儿重疾 H 不含身故责任，`身故保额` 记 0；学平险保单在学校，身故额度待补，所以合计写「待补」。少儿意外现在就可以按意外医疗和伤残给建议；身故保额等拿到学平险身故额度后再定，两者合计不超过 50 万。

其余格子：

- 爸爸重疾「一般（示例重疾 B 30 万，甲状腺相关除外）」：除外后仍买到了，按保额打档，30 万落在 30–50 万。
- 爸爸医疗「核保受限（百万医疗被拒，单位补充医疗 + 惠民保兜底，离职即失效）」：需要医疗险，被拒，手上只剩不看健康的兜底。
- 妈妈寿险「不足（无寿险，共同承担房贷）」：有收入、共同承担负债，寿险为 0。
- 妈妈重疾「充分（示例重疾 E 50 万，至 70 岁）」；哥哥重疾 50 万至 70 岁、妹妹重疾 50 万保 30 年（覆盖到能自主投保），同样「充分」。
- 妈妈、哥哥医疗「充分」：保证续保 20 年。外公外婆医疗「一般」：防癌医疗不保证续保 + 惠民保。
- 外婆意外「不足（骨质疏松，未配老年意外）」；妹妹意外「不适用（未入托婴儿，入托前再配）」。
- 哥哥意外、妹妹医疗、爸爸年金、外婆年金「缺资料」：学平险保单在学校、居民医保待确认、企业年金与养老金资料未取得。
- 外公外婆重疾「不适用（保费倒挂，以防癌医疗替代）」。

关键缺口第一条是爸爸寿险：主要收入来源，覆盖约 55%，差约 162 万；第二条是爸爸医疗，现有兜底离职即失效。

## 常见错误

| 错误 | 正确做法 |
| --- | --- |
| 没录入的保单当成没保障 | 先读 TODO，未录入的标「缺资料」 |
| 被拒保的格子打「不足」 | 标「核保受限」，写替代路径 |
| 加费承保也标「核保受限」 | 按买到的保额打档，括号注明加费 |
| 给子女算寿险缺口 | 子女寿险「不适用」，只核对身故保额合计上限 |
| 未成年人只看新单身故保额 | 全部保单 `身故保额` 加总后和上限比 |
| 只看医疗险保额不看续保 | 一年期最高「一般」 |
| 团险当作长期保障 | 最高「一般」，注明离职即失效 |
| 老人硬配重疾 | 保费倒挂时「不适用」，改防癌医疗 |
| 矩阵当历史快照不改 | 矩阵始终是当前状态；历史档位记在年度复盘里 |
