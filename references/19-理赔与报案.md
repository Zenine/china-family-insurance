# 19 理赔与报案

结论：出险后按「保留证据 → 报案 → 准备材料 → 提交 → 跟进答复 → 补件 → 异议与投诉」七步走；报案时限、材料清单、答复时效以每份保单的合同条款为准，条款里找不到就在台账写「未识别」，不用常见做法填空；法律只兜底几条通用规则，下文逐条写明出处。

## 先查台账

出险当天先打开出险成员的全部台账（`policies/<代号>/`），逐份看 `templates/policy.md` 里的四个字段：

| 字段 | 用途 | 没有时 |
| --- | --- | --- |
| 客服电话 | 报案 | 看保单首页或保险公司官方渠道 |
| 报案时限 | 决定先报哪家 | 翻条款「保险事故通知」「保险金申请」一节 |
| 理赔材料（摘要） | 准备材料 | 翻条款「保险金申请」一节，或报案时问清 |
| 理赔渠道 | 提交方式（线上、电话、柜面、邮寄） | 报案时问清 |

写法：

- 读过完整条款、确实没有写的，写「未识别」，报案时向保险公司问清并保留答复记录（短信、邮件、工单号）。
- 还没拿到条款原文的，写「待补」，按 `references/03-保单台账与资料提取.md` 补资料。
- 不写「一般 3 天内报案」「通常 30 天赔完」这类常识值；条款写多少就记多少。

新保单收到时就按 `templates/new-policy-check.md` 第五项把这几个字段填好，出险时就不用临时找。

## 法律兜底的几条规则

下列条文核对日期均为 2026-11-21，以官方原文为准；核定、支付期限合同另有约定的，按合同。

| 环节 | 规则 | 出处 |
| --- | --- | --- |
| 通知 | 知道保险事故发生后应当及时通知保险人；故意或重大过失没有及时通知、导致事故性质、原因、损失程度难以确定的，无法确定的部分保险人不赔（保险人通过其他途径已经或应当及时知道的除外） | 《中华人民共和国保险法》第二十一条 |
| 材料 | 申请时提供自己能提供的、与确认事故性质、原因、损失程度有关的证明和资料；保险人认为资料不完整的，应当及时**一次性**通知补充 | 《中华人民共和国保险法》第二十二条 |
| 核定 | 收到请求后及时核定；情形复杂的，30 日内核定，合同另有约定的除外；核定结果要通知；属于保险责任的，达成协议后 10 日内支付，合同对期限另有约定的按约定 | 《中华人民共和国保险法》第二十三条 |
| 拒赔 | 核定不属于保险责任的，自核定之日起 3 日内发出拒绝赔偿或拒绝给付保险金通知书，并说明理由 | 《中华人民共和国保险法》第二十四条 |
| 先予支付 | 收到请求和有关证明、资料之日起 60 日内数额仍不能确定的，按已能确定的数额先付，最终确定后补差额 | 《中华人民共和国保险法》第二十五条 |
| 诉讼时效 | 人寿保险以外的保险 2 年，人寿保险 5 年，都从知道或应当知道保险事故发生之日起算 | 《中华人民共和国保险法》第二十六条 |
| 多份医疗险 | 同时有多份有效的费用补偿型医疗保险的，被保险人可以自主决定理赔申请顺序；费用补偿型医疗保险的给付金额不超过实际发生的医疗、康复费用 | 《健康保险管理办法》（中国银保监会令 2019 年第 3 号）第二十五条、第五条 |
| 投诉处理 | 保险公司对事实清楚、争议简单的投诉，自收到之日起 15 日内作出处理决定并告知；复杂的可延长至 30 日，特别复杂的经审批并告知后可再延长 30 日；对分支机构处理结果有异议的，收到决定之日起 30 日内可向其上级机构书面申请核查 | 《银行业保险业消费投诉处理管理办法》（中国银保监会令 2020 年第 3 号）第十八条、第二十条 |

注意：第二十六条的 2 年 / 5 年是打官司的时效，不是报案时限。报案时限看合同，合同没写也要尽早通知，晚报可能因为事故原因查不清而少赔。

## 出险后七步

1. **保留证据**：先就医、先处理事故，同时留下能证明「发生了什么」的东西——病历、检查报告、发票、费用清单、事故现场照片、报警回执、交通事故认定书、证人联系方式。意外事故当场拍照，事后很难补。
2. **报案**：按台账逐份报，每份保单单独报案；只要可能属于保险责任就报，赔不赔由保险公司核定。记下报案日期、方式、工单号或案件号，写进 `TODO.md`。
3. **准备材料**：按台账「理赔材料（摘要）」和报案时保险公司给的清单准备；清单里有、手上没有的，问清能否用替代材料。材料结构见下一节。
4. **提交**：按「理赔渠道」提交。线上提交的保存提交截图和回执；邮寄的用能查轨迹的方式并留底单；原件寄出前全部拍照或扫描。
5. **跟进答复**：从提交齐材料那天起记日期。超过合同约定的核定期限、合同没约定时超过 30 日仍无结果的，打客服电话要书面进度，并提醒第二十三条的期限。
6. **补件**：保险公司要求补材料时，按第二十二条应一次性列明；分多次要补件的，请对方书面列出完整清单。补件日期记进 TODO。
7. **异议与投诉**：收到拒赔或少赔结论，先要书面通知书和理由（第二十四条），对照条款核对是否属于责任免除、等待期、健康告知问题。仍有异议的，按顺序：
   - 向保险公司书面申诉或投诉（客服电话、官方 App 或网站的投诉入口），记下受理编号；处理期限见上表。
   - 对分支机构的处理结果不服的，30 日内向其上级机构申请核查。
   - 向国家金融监督管理总局投诉：银行业保险业消费投诉热线 12378（号码见国家金融监督管理总局官网「机构概况」页，核对日期 2026-11-21）。
   - 双方同意的，可以申请调解组织调解；仍不能解决的，在诉讼时效内向法院起诉。

## 按险种的材料结构

下面是材料的类别，具体到哪一份、要原件还是复印件，以合同「保险金申请」条款和保险公司给的清单为准。

| 类别 | 医疗险（报销） | 重疾险（给付） | 寿险（身故） | 意外险 |
| --- | --- | --- | --- | --- |
| 申请与身份 | 理赔申请书、被保险人身份证明、收款账户 | 同左 | 理赔申请书、受益人身份证明与收款账户 | 同医疗或寿险，看申请的是哪项责任 |
| 关系证明 | 代办或未成年人申请时的监护或委托证明 | 同左 | 法定受益时证明继承关系的材料 | 身故申请时同寿险 |
| 诊断与病历 | 门急诊病历、住院病历、出院小结、诊断证明 | 诊断证明、病理或检查报告等合同重疾定义要求的诊断依据 | 医学死亡证明或死亡相关证明 | 门急诊病历、诊断证明 |
| 费用凭证 | 医疗费用发票、费用明细清单、医保结算单；先经其他渠道报销的附分割单或结算证明 | 一般不需要 | 不需要 | 申请意外医疗时同医疗险 |
| 事故证明 | 不需要 | 不需要 | 非疾病身故时的事故证明 | 事故经过说明、报警回执、交通事故认定书等能证明意外的材料；伤残申请附伤残鉴定 |
| 户籍注销 | 不需要 | 不需要 | 户籍注销证明等 | 身故申请时同寿险 |

要点：

- **医疗险**按发票和清单算钱，凭证不全会被扣减；是否要求先经社保结算、未经结算如何赔付，以条款为准。
- **重疾险**看的是诊断是否符合合同定义，不看花了多少钱；确诊后就能申请，不必等治疗结束。
- **寿险**的申请人是受益人；受益人写「法定」的，要证明继承关系，材料最多、耗时最长，所以录台账时就核对受益人。
- **意外险**的关键是证明「意外」：外来、突发、非本意、非疾病。事故证明当时不取，事后很难补。

## 多份保单的报销顺序

医疗费用（报销型）按下面的常用顺序走，前一层结完再报下一层：

社保结算（职工医保或城乡居民医保）→ 单位补充医疗 → 惠民保 → 百万医疗或少儿医疗等个人医疗险。

- 依据：法规允许被保险人自主决定多份费用补偿型医疗保险的申请顺序（《健康保险管理办法》第二十五条）；常用顺序把免赔额低、报销范围窄的放前面，免赔额高的个人医疗险放最后，用它兜剩下的大额自付。个人医疗险条款里「其他途径已获补偿的部分能否抵扣免赔额」写法不一，以条款为准，条款里找不到写「未识别」。
- 报销型不能重复报，几家合计不超过实际花费（同办法第五条）。
- **给付型可以同时申请**：重疾险、意外伤残或身故、定额给付的住院津贴，按合同约定的条件各自给付，不受报销顺序限制，和医疗险同时报即可。
- 出险后先在医院用医保卡结算，别因为有商业医疗险就自费结算。

顺序也写进家庭应急交接卡片（`references/13-年度复盘与事件更新.md` 的「家庭应急交接」）。

## 理赔对续保的影响

| 保单类型 | 理赔后续保 | 出处 |
| --- | --- | --- |
| 保证续保的医疗险（长期医疗） | 保证续保期内，前一期届满前申请续保的，保险公司必须按原条款和约定费率继续承保；续保时不得减少保险责任、增加责任免除。费率能否整体调整看条款 | 《健康保险管理办法》第四条、第二十一条 |
| 不保证续保的一年期医疗险（短期健康险） | 期满后要重新申请，经保险公司同意才能获得新合同；理赔过的成员能否续上、是否加除外，结果不确定 | 《中国银保监会办公厅关于规范短期健康保险业务有关问题的通知》（银保监办发〔2021〕7号）第三条 |
| 重疾险 | 单次赔付的给付后合同或重疾责任通常终止；多次赔付、轻中症赔后豁免保费等按条款 | 以合同条款为准 |
| 寿险 | 身故给付后合同终止 | 以合同条款为准 |
| 意外险 | 多为一年期，续保规则同一年期产品，看条款 | 以合同条款为准 |

所以：

- 一年期不保证续保的医疗险理赔后，把台账「续保或调整建议」改成「理赔后续保待确认」，到期前一个月确认能否续上；续不上就按 `references/13-年度复盘与事件更新.md` 的换保顺序补新单。
- 理赔过的疾病，以后新投保任何健康类保险都要如实告知（`references/06-核保策略.md`）；小额门诊也报了的，后面核保同样会问到。小额理赔要不要报，按「这份保单续保受不受影响」和「金额」自己权衡，不因为担心核保就隐瞒已发生的就医。

## 票据归口

医疗发票原件通常只有一份，多家报销时：

1. **先给要原件的那家**：一般是顺序里先报的那一层（单位补充医疗、惠民保常要原件）；报案时先问每家「要原件还是复印件、电子发票是否可以」。
2. **拿回分割单或结算证明**：先报的机构收走原件后，请对方出具分割单、理赔结算证明或加盖印章的复印件，写明已赔金额；下一家凭它报剩余部分。
3. **电子票据**可以多次下载打印，但各家都会按其他渠道已赔金额扣减，提交时如实写明其他渠道已报部分。
4. **寄出前全部扫描**：发票、清单、病历、诊断证明扫描后按 `references/14-隐私分级与资料原件.md` 存放（文件名「代号-类型-日期」）；库正文只写诊断结论和文件名，不抄病历原文。
5. 给付型（重疾、意外伤残）一般只要诊断类材料的复印件，不占发票原件；以保险公司清单为准。

## 示例

示例家庭哥哥（10 岁，城乡居民医保）在学校摔伤骨折，住院手术，假设总费用 3 万元。

1. **查台账**：哥哥名下有 `examples/demo-family/policies/son/medical-shilijiankang-2022.md`（示例少儿医疗 I，免赔额 1 万元）和 `examples/demo-family/policies/son/critical-shilirenshou-2020.md`（示例少儿重疾 H，骨折不属于重疾，不报）；学平险保单在学校、没有台账。两份台账都没有「理赔」一节的字段，先翻条款补「报案时限」「理赔材料（摘要）」「理赔渠道」，条款里找不到的写「未识别」，学平险的三项写「待补」。
2. **报案**：当天打示例健康客服电话报少儿医疗 I；同时联系班主任，请学校向学平险的承保公司报案并拿到报案方式和材料清单——这也顺带完成 `examples/demo-family/TODO.md` 里「向学校取得哥哥学平险保单」一条。
3. **顺序**：出院时用居民医保卡结算 → 学平险（意外医疗通常免赔低，具体看保单）→ 少儿医疗 I 报剩余部分（扣掉其他渠道已赔部分后是否还超过 1 万元免赔额，按条款算，算不出就照实提交由保险公司核定）。
4. **票据**：发票原件先给学平险；拿回分割单后，把分割单、费用清单、出院小结、医保结算单交给示例健康。全部材料扫描为 `.private/son-住院-2026.pdf` 一类文件名。
5. **记录**：理赔中写 TODO；结案后在 `members/son.md` 备注写「2026-xx 骨折住院：学平险赔付 x 元，少儿医疗 I 赔付 x 元」，台账评估备注同样一行，CHANGELOG 一行。少儿医疗 I 保证续保 20 年，保证期内理赔不影响续保（费率能否整体调整看条款），续保建议不用改。

## 常见错误

| 错误 | 正确做法 |
| --- | --- |
| 报案时限按「一般 3 天」「一般 10 天」记进台账 | 照条款写；条款里没有写「未识别」，报案时问清并留记录 |
| 把 2 年 / 5 年诉讼时效当报案期限，拖着不报 | 出险后尽早逐份报案 |
| 只报一家，忘了还有学平险、单位团险、给付型保单 | 出险当天把该成员全部台账过一遍 |
| 有商业医疗险就自费结算、不走医保 | 先医保结算，再按顺序报 |
| 发票原件先寄给了最后报的那家 | 先给要原件的那家，拿回分割单再报下一家 |
| 原件寄出前没留底 | 全部扫描后再寄，用可查轨迹的方式 |
| 保险公司口头说「材料不全」就一次次补 | 请对方书面一次性列出完整补件清单 |
| 收到拒赔只听电话结论 | 要拒赔通知书和理由，对照条款，再走申诉、核查、12378 |
| 以为理赔一定影响续保，或一定不影响 | 先看是否保证续保，按上表判断 |
| 把病历全文抄进成员档案 | 正文只写诊断结论，原件按隐私分级存放 |
