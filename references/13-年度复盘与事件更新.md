# 13 年度复盘与事件更新

结论：库靠两种节奏保持准确——每 12 个月一次年度复盘，和事件发生后 30 天内的事件更新；两者都按 `references/01-建库与日常维护.md` 的固定顺序（台账 → 矩阵 → 待办 → 变更记录 → 总览页）落地。

## 事件更新

下列事件发生后 30 天内更新库：

| 事件 | 要改的文件 | 要重看的档位 |
| --- | --- | --- |
| 新投保 | 新建 `policies/<代号>/*.md`；成员档案「已有保单」与「年度提醒」 | 该成员对应险种 |
| 续保 / 交费 | 台账「生效日 / 下次交费日」「年保费」；条款或保额有变就改对应字段 | 续保条件变了才改档 |
| 停售 / 不能续保 | 台账「续保或调整建议」；TODO 加换保一条（硬期限段） | 医疗档位 |
| 退保 / 到期不续 | 台账连同原件移到 `policies/<代号>/` 下的 `_ended/` 子目录，或删除台账只留原件 | 对应险种 |
| 体检 / 复查 | 成员档案「健康状况」「最近一次体检」；原件按 `references/14-隐私分级与资料原件.md` 存放 | 核保受限的格子是否可以重试 |
| 核保结果（拒保、延期、加费、除外、标准体） | 成员档案；有保单就建台账 | 「核保受限」与按保额打档之间的切换 |
| 出生 / 结婚 / 离婚 / 去世 | 新增或调整 `members/<代号>.md`；受益人与投保人字段 | 全家 |
| 换工作 / 离职 / 收入大变 | 成员档案经济状况；团险台账标失效 | 团险覆盖的意外与医疗、寿险应保额 |
| 购房 / 还清贷款 / 新增大额负债 | 成员档案「主要负债」 | 寿险应保额 |
| 确诊重大疾病 / 体检重大异常 | 成员档案；TODO 加理赔或报案一条 | 该成员全部险种 |
| 出险理赔 | 台账备注写理赔结论与时间；医疗险理赔后看是否影响续保 | 医疗档位 |

`policies/<代号>/_ended/` 下的文件不会进入总览页（总览页只读 `policies/<代号>/` 一层的 `.md`）。

**新投保后立刻做的四步**：建台账 → 改矩阵 → 重建总览页 → 删掉对应 TODO 并记 CHANGELOG。投保当天就做，不等复盘。

**换保顺序**：新保单先投、过了等待期，再让旧保单到期不续；中间允许重叠。不为更好的产品退掉还在保障期内的旧保单。有既往症的成员，原有医疗险只续不退。

## 年度复盘

每年固定一个月做（建议选全家续保最集中的月份之前），用 `analysis/_review-template.md`（来自 `templates/review.md`）复制出 `analysis/review-YYYY.md`：

1. **家庭变化**：成员增减、年龄跨档（满 1 周岁、满 10 / 18 周岁、满 50 / 60 岁等影响费率或投保上限的节点）、收入与负债变化、健康变化（只写结论）。
2. **在保对账**：按 `references/03-保单台账与资料提取.md` 的「在保状态对账」核对全部保单，找出失效、漏记、重复。
3. **保单变化**：新增、到期、停售、退保、续保结果、全家年保费合计。
4. **矩阵重算**：全表重新打档。把变化写成「成员 · 险种 · 原档位 → 新档位」记进复盘文件；`analysis/gap_matrix.md` 直接改成新状态。
5. **待办清理**：已完成的删掉并记 CHANGELOG；过期的硬期限重新判断；资料缺口重新列。
6. **下一年动作**：续保与交费月份汇总进 TODO「年度提醒」；新缺口写进 TODO；需要新配置时按 `references/17-推荐方案输出.md` 出 `recommendations/YYYY-MM-DD.md`。
7. **年龄与提醒更新**：成员档案里括号中的年龄改成当年年龄。
8. **重建总览页**，CHANGELOG 记「完成 YYYY 年度复盘」。

## 家庭应急交接

库通常由一个人维护。复盘时确认另一位家庭成员（通常是配偶）知道：

- 保单原件和库放在哪里；
- 总览页怎么打开、口令是什么；
- 各保单的续费方式与扣费日；
- 出险后先联系谁：报案时限、客服电话、医疗费用的报销顺序（社保结算 → 单位补充医疗 → 惠民保 → 百万医疗，以各保单条款为准）、发票原件只有一份时先给哪家并申请分割单。

交接卡片做成纸质或离线文件，不写证件号和完整保单号。

## 示例

示例家庭爸爸换工作（离职失去团险）：`examples/demo-family/policies/self/group-shilirenshou-2026.md` 的意外 50 万和补充医疗在离职当月失效。更新：台账移到 `policies/self/_ended/` → `members/self.md` 改职业、单位团险一行改为「已失效」→ 矩阵爸爸意外由「一般」改为「不足」；爸爸医疗本来就靠团险补充医疗兜底，失效后只剩惠民保，仍是「核保受限」，括号里的兜底说明同步改 → TODO 把「给爸爸配个人意外 100 万」移到最前（硬期限：离职前投好），新单位有团险的，拿到服务手册后建新台账 → CHANGELOG 记一行 → 重建总览页。

外公外婆的示例防癌医疗 K 停售（`examples/demo-family/policies/father/cancer-medical-shilijiankang-2024.md` 写明不保证续保）：两份台账「续保或调整建议」写「已停售，到期后不能续保」→ TODO 硬期限段加「到期前投新的防癌医疗或中老年医疗」，写明到期日 → 新单生效、过了等待期后，旧单到期不续，台账移到 `_ended/` → 矩阵外公外婆医疗按新单的续保条件重新打档。

爸爸 2027-03 复查（`examples/demo-family/TODO.md` 已列）：复查结果写进 `members/self.md`；血压连续控制达标满 1 年时，带复查结果重新询问百万医疗核保。若以加费或除外承保，矩阵爸爸医疗由「核保受限」改为按续保条件打档；若仍被拒，保持「核保受限」，备注更新复查时间与结论。甲状腺结节复查稳定时，同时考虑另投一份重疾把保额补到 50 万。

年度复盘时，妹妹满 10 周岁的那一年，未成年人身故保险金合计上限由 20 万变为 50 万，复盘里要重看她的意外身故保额。

## 常见错误

| 错误 | 正确做法 |
| --- | --- |
| 投保后等到年底才录 | 当天按四步更新 |
| 先退旧保单再投新保单 | 新单过等待期后，旧单到期不续 |
| 离职后团险还算在矩阵里 | 离职即标失效，重算意外与医疗 |
| 复盘只看新增保单，不对账 | 每年做一次在保对账 |
| 复盘结论只在聊天里 | 写进 `analysis/review-YYYY.md` 并更新矩阵与 TODO |
| 只有维护者知道口令和保单位置 | 复盘时做家庭应急交接 |
