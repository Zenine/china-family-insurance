# 02 成员档案

结论：每位家庭成员一个 `members/<代号>.md`，记录打缺口所需的四类事实——基础信息、健康结论、经济角色、已有保障；原件不进档案，只写结论和文件名。

## 规则

1. **一人一档**：文件名用英文代号（`self`、`spouse`、`daughter`、`son`、`father`、`mother`），称呼写在 `- 代号 / 称呼：` 字段里，例如「爸爸」。称呼只用家庭内的叫法，不写真实姓名。
2. **字段写法**：每个字段一行，`- 字段：值`，冒号用中文全角。总览页靠这个格式读取 `代号 / 称呼`、`家庭角色` 和 `## 备注` 段落，不要改字段名。模板见 `templates/member.md`。
3. **年龄锚定出生年月**：写 `出生年月：2019-03（7 岁）`，以出生年月为准，括号里的年龄每年复盘时更新。投保窗口（满 28 天、未满 1 周岁、满 60 岁等）一律按出生日期推算，不按「几岁」心算。
4. **健康只写结论**：既往病史写诊断、确诊年份、治疗方式、控制情况和是否痊愈；化验单原值只摘核保会问到的关键指标（如血压、结节分级），完整报告单独存放（见 `references/14-隐私分级与资料原件.md`），档案里写文件名。
5. **核保结论单独记**：拒保、延期、加费、除外、标准体，连同时间和险种写进「既往病史」或「备注」。核保结论决定缺口矩阵里能不能标「核保受限」。
6. **家庭角色必填**：主要收入来源 / 照护者 / 被抚养 / 退休。寿险是否适用、优先级怎么排都从这里来。
7. **经济状况写到能算保额**：税后年收入、负债余额与剩余年限、可接受的全家年保费预算。预算缺失时矩阵可以出，但配置建议出不了保额，要在 TODO 里列为待补。
8. **已有保单勾选清单**：每个险种一行，有就勾选并写保单代称，没有就写「不配置」「被拒」「待确认」中的一个，不留空。空着的格子在矩阵里只能打「缺资料」。
9. **年度提醒**：续保月、交费月、居民医保缴费月写在「年度提醒」，复盘时汇总进 TODO 的年度提醒。
10. **未知就写未知**：用户不知道或没提供的，写「资料未取得」或「待补」，不估、不编。

## 示例

示例家庭的爸爸 `examples/demo-family/members/self.md`：

- 基础信息：`代号 / 称呼：爸爸`，`出生年月：1984-06（42 岁）`，销售主管 2 类（外勤较多），城镇职工医保 + 单位团险。
- 健康：「高血压 2 级，2022 年确诊，两种降压药控制，近半年血压约 135/85 mmHg；甲状腺结节 TI-RADS 3 类，每年复查超声，大小稳定」——诊断、年份、治疗、关键指标、复查情况一句写完；体检报告只写 `.private/self-体检-2026.pdf`。
- 核保结论：已有保单清单里写「寿险：示例定寿 A 200 万（高血压加费承保）」「重疾：示例重疾 B 30 万（甲状腺相关除外承保）」「医疗：2025 年百万医疗人工核保拒保（高血压 2 级）」。
- 经济：税后 38 万，房贷余额 200 万剩 25 年，全家预算每年 4 万以内，角色「主要收入来源」；另记家庭年支出（每个孩子约 3 万 / 年、妈妈个人生活费约 6 万 / 年），寿险应保额要用。

外婆 `examples/demo-family/members/mother.md` 的年收入写「资料未取得」，年金一栏因此在矩阵里是「缺资料」，并在 `examples/demo-family/TODO.md` 列了补资料一条。

## 常见错误

| 错误 | 正确做法 |
| --- | --- |
| 档案里写真实姓名、身份证号 | 只写家庭称呼；证件号不进库正文 |
| 把整张化验单数值抄进档案 | 写诊断与控制情况，摘一两个核保关键指标，原件单独存放 |
| 只写「7 岁」不写出生年月 | 写出生年月，年龄放括号，窗口按日期推算 |
| 核保被拒只在聊天里说过 | 写进档案，含时间与险种 |
| 已有保单留空 | 写「不配置 / 被拒 / 待确认」之一 |
| 不知道收入就估一个数 | 写「资料未取得」，TODO 列待补 |
