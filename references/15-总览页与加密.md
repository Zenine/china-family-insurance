# 15 总览页与加密

结论：总览页是从库生成的单个 `site/index.html`，明文区只有成员称呼与五险种档位，明细用家庭口令加密；默认在本机打开，口令用 4 个以上随机词；确需外网访问时选能挡住访问的方案，GitHub Pro 只能配强口令。

## 生成

在本 skill 目录下运行：

```
node scripts/build-dashboard.mjs <库目录>
```

脚本做四件事：读 `members/`、`policies/`、`analysis/gap_matrix.md` → 生成明文总览与明细 → 用口令加密明细（PBKDF2-SHA256 21 万次 + AES-256-GCM）并当场解密自检 → 写出 `<库目录>/site/index.html`。库在 Git 仓库里而 `.private/` 没被忽略时，脚本拒绝生成。

- 明文区：成员称呼、五险种档位、生成日期。档位为「核保受限」的格子按「不足」显示——单独一个标记本身就会暴露健康状况；原档位只在加密明细里。
- 加密明细：每位成员的家庭角色、备注、各险种档位，每份保单的产品名、公司、险种、主险保额、保障期限、年保费、生效日 / 下次交费日、保单号末 4 位、续保建议、客服电话（号码可含空格、连字符与开头的 +；多个号码用「、」「／」「；」「，」「或」「转」分隔时，点击只拨第一个）。明细表的客服电话显示在产品名下方。
- 页面由脚本整体生成，不手改；改了台账就重新生成。
- 页面要放在别的位置时加 `--out <输出文件>`，只接受库目录内、以 `.html` 结尾的相对路径，例如 `--out site/insurance-dashboard/index.html`；`site/index.html` 已是别的页面时用它，避免覆盖。

`node scripts/encrypt.mjs <json> [--out 文件] [--library <库目录>]` 用于单独加密一份自己整理的 JSON（口令文件从 `--library` 指定的库目录读，不写时取当前工作目录；口令来源同下），输入 JSON 放在 `.private/`。

## 口令

**三种来源，按顺序取第一个可用的：**

1. 环境变量 `DASHBOARD_PASSPHRASE`；
2. 库内文件 `.private/dashboard-passphrase` 的文件内容（去掉首尾空白）；
3. 终端交互输入（不回显）。只有在真正的终端里运行才会提示输入；AI 工具代为运行命令时通常没有终端，前两种都没有就会报「未提供家庭口令」。

**选哪种：**

- 想让 AI 全自动更新总览页：用口令文件。由用户本人在库目录的终端创建更好：

  macOS、Linux：

  ```
  mkdir -p .private
  printf '%s\n' '<口令>' > .private/dashboard-passphrase
  chmod 600 .private/dashboard-passphrase
  ```

  Windows PowerShell（`Read-Host` 输入时不回显，口令不进命令历史）：

  ```
  New-Item -ItemType Directory -Force .private | Out-Null
  $p = Read-Host '家庭口令' -AsSecureString
  [System.Net.NetworkCredential]::new('', $p).Password | Set-Content -NoNewline -Encoding utf8 .private\dashboard-passphrase
  Remove-Variable p
  ```

  Windows 上不需要 `chmod`；库在别人也能登录的电脑上时，右键 `.private` 文件夹 →「属性」→「安全」，只保留自己的账户。也可以用记事本新建这个文件，只写口令一行，另存为时文件名写 `dashboard-passphrase`、保存类型选「所有文件」，避免被加上 `.txt`。

- 不想让 AI 接触口令：不建口令文件，由用户本人在终端运行 `node scripts/build-dashboard.mjs <库目录>`，交互输入口令。
- 临时使用：在命令前设环境变量，命令会留在终端历史里，用完清掉。

**用户在对话里直接给口令时**：库是 Git 仓库的，先在库目录运行 `git check-ignore -v .private/x` 确认 `.private/` 被忽略；再用 AI 工具自带的写文件功能创建 `.private/dashboard-passphrase`，不用 `printf`、`echo` 这类把口令写在命令里的方式，写完把权限改为 600；然后运行 `node scripts/build-dashboard.mjs <库目录>`，口令不写进这条命令，也不写进 TODO、CHANGELOG；生成后提醒一次两件事——口令已经进了会话记录，以及口令不满足下面的强度要求时要换（例如短、带年份、有规律）。

**口令会进入 AI 会话记录**：AI 读了口令文件、或用户把口令发给 AI、或 AI 执行的命令里带着口令，口令就出现在该 AI 工具的会话记录里，可能被工具保存或上传。想避免，就用上面「不想让 AI 接触口令」的方式。

**口令强度**：用 4 个以上随机挑选的词，用连字符连起来，例如 `海带-台灯-候鸟-铅笔-七月`（这个例子已公开，不要用）。词要随机挑（翻字典、掷骰子），不用生日、电话、门牌、孩子名字、常见诗句。加密次数再高也挡不住弱口令：短口令和有规律的口令可以被批量猜出。

**换口令**：怀疑泄露、家庭成员变动、口令曾在外网页面上使用过时，改口令文件内容后重新生成；旧页面的所有副本都删掉，因为旧页面仍可用旧口令解开。

**在本设备记住口令**：解锁框下勾选「在本设备记住口令」，口令以明文存进这台设备的浏览器存储，之后打开页面自动解锁；页头「忘记本设备口令」一键清除。只在本人专用、设了锁屏密码的设备上勾选；共用电脑、他人手机、公共设备不勾。设备丢失或口令更换后，在该设备上点「忘记本设备口令」或清除浏览器数据。隐私模式或浏览器禁用存储时不显示该选项。

## 打开

- **默认本机打开**：双击 `site/index.html`，输入口令解锁。
- 浏览器在本地文件下拒绝解密时，用本机预览服务：

  ```
  node scripts/preview.mjs <库目录>
  ```

  它只监听 `127.0.0.1`（默认端口 8787，可用 `--port` 改为 1–65535 之间的整数；端口被占用时会提示换一个），同一局域网的其他设备也访问不到；`site/` 里指向外部的符号链接不会被提供。
- 手机上看：把 `site/index.html` 通过私密渠道传到手机，用浏览器打开；不要发到群聊或公开网盘链接。

## 部署到外网的风险

把页面放到任何公网地址之前，用户要知道三件事：

1. **加密载荷任何人都能下载**。页面能打开，载荷就能被保存下来，在自己电脑上离线无限次猜口令，没有次数限制，也不会留下痕迹。
2. **口令弱就等于公开**。离线猜测只受算力限制；弱口令被猜中后，全家的产品、保费、续保日期、核保备注一览无余。
3. **页面地址可能被搜索引擎收录**。页面带 `noindex` 标记，但不保证所有搜索引擎遵守；地址被转发、被浏览器同步后也会扩散。明文区的称呼与档位对所有访问者可见，加上地址里的用户名，可能被认出是哪一家。

**建议本机查看。** 本 skill 不提供部署脚本。

GitHub 免费账号不能从私有仓库发布网页；从公开仓库发布等于把整个库公开，不可以这样做。

## 确需外网访问时的付费方案

费用为 2026-11-20 查询的量级，以各家官网当前价格为准。

| 方案 | 费用量级 | 载荷是否公开 | 取舍 |
| --- | --- | --- | --- |
| GitHub Pro + 私有仓库网页发布 | 约 4 美元 / 月 | 公开：仓库私有，但发布出的网页任何人都能访问 | 配置最简单；只解决「仓库不公开」，不解决「页面可下载」，必须用强口令；用 GitHub Actions 只发布 `site/` 目录，直接按分支根目录发布会把整个库公开 |
| Cloudflare Pages + Cloudflare Access | Pages 免费；Access 所在的 Zero Trust 免费档最多 50 个用户，超出后按用户付费（约 7 美元 / 用户 / 月） | 不公开：访问者先用白名单邮箱收验证码登录，通过后才能拿到页面 | 家庭用量通常在免费档内；需要注册 Cloudflare 账号并配置访问策略，配置错了等于公开，配好后要用未授权邮箱实测一次被拦下 |
| 自有服务器 + HTTP 认证 | 入门云服务器每月几十元人民币起 | 不公开：先过用户名密码，再过页面口令 | 完全自控；要自己维护系统更新与 HTTPS 证书，HTTP 认证必须走 HTTPS；中国大陆服务器绑定域名需要先办 ICP 备案 |

无论选哪种：口令仍按上面的强度要求；外网版和本机版用同一套生成流程；部署后用一台没登录过的设备访问一次，确认看到的是登录或口令界面。

## 示例

示例家庭的总览页（演示口令 `demo-2026`，只用于公开演示，强度不够）：

```
DASHBOARD_PASSPHRASE=demo-2026 DASHBOARD_TODAY=2026-11-20 node scripts/build-dashboard.mjs examples/demo-family
node scripts/preview.mjs examples/demo-family
```

打开 `http://127.0.0.1:8787/`：明文区爸爸医疗一格是「不足」（矩阵里是「核保受限」），妈妈寿险也是「不足」；输入口令后，明细里爸爸医疗显示「核保受限」，备注写先试防癌医疗、血压控制满 1 年后重试百万医疗，保单列出示例定寿 A 的保额、保障期限、年保费、生效日与下次交费日、末 4 位 0001。近 60 天待办按 2026-11-20 算，列出妈妈示例重疾 E 已逾期的交费日、宽限期止日，团险的到期日，以及老年意外、百万医疗的到期日与交费日；每份保单下点「到期、宽限期与理赔」展开六个理赔相关字段。生成好的页面在 `examples/demo-family/site/index.html`。

`DASHBOARD_TODAY=YYYY-MM-DD` 把生成日期和待办基准日固定为指定日期，只用于示例这类需要可复现的构建；家庭库不设，默认取当天。

## 常见错误

| 错误 | 正确做法 |
| --- | --- |
| 手改 `site/index.html` | 改台账后重新生成 |
| 用生日、手机号、单个英文词当口令 | 4 个以上随机词 |
| 把口令写进 TODO、CHANGELOG 或提交信息 | 只放 `.private/dashboard-passphrase` 或用户脑子里 |
| AI 代跑命令时等它弹出口令输入 | AI 环境没有终端，改用口令文件，或由用户本人在终端运行 |
| 以为私有仓库的网页也是私有的 | 网页公开，载荷可下载 |
| 换了口令但旧页面还挂在外网 | 删除旧页面所有副本 |
