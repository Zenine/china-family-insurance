# 20 投保后操作

结论：保单买完后要管住五件事——按时交费（记住宽限期止日）、断交后两年内争取复效、受益人和联系方式随家庭变化更新、退保前先算清损失和重新投保的代价、让配偶知道保单在哪和出险找谁；每份保单的天数、费用和手续以合同条款为准，条款里找不到就在台账写「未识别」；法律只兜底下表几条通用规则。

## 法律与监管兜底的规则

下列条文核对日期均为 2026-11-21，以官方原文为准；合同另有约定且法律允许约定的，按合同。

| 环节 | 规则 | 出处 |
| --- | --- | --- |
| 分期交费与宽限 | 交了首期保费后，除合同另有约定外，保险公司催告之日起超过 30 日、或超过约定交费期限 60 日仍未交当期保费的，合同效力中止，或按合同约定减少保险金额；在这个期限内出险，保险公司照合同给付，可以扣掉欠交的保费 | 《中华人民共和国保险法》第三十六条 |
| 复效 | 效力中止后，与保险公司协商达成协议、补交保费，合同效力恢复；中止之日起满 2 年没有达成协议的，保险公司有权解除合同，按合同约定退还现金价值 | 《中华人民共和国保险法》第三十七条 |
| 复效后的自杀条款 | 以死亡为给付条件的合同，自合同成立或效力恢复之日起 2 年内被保险人自杀的，保险公司不给付（自杀时为无民事行为能力人的除外），按合同约定退还现金价值 | 《中华人民共和国保险法》第四十四条 |
| 退保 | 合同成立后投保人可以解除合同（法律另有规定或合同另有约定的除外）；保险公司自收到解除通知之日起 30 日内，按合同约定退还现金价值 | 《中华人民共和国保险法》第十五条、第四十七条 |
| 告知不实的解除期限 | 投保时故意或重大过失没有如实告知的，保险公司可以解除合同；但自合同成立之日起超过 2 年的，不得以此解除，出险应当赔付 | 《中华人民共和国保险法》第十六条 |
| 年龄申报不实 | 真实年龄不符合合同年龄限制的，保险公司可以解除合同并退现金价值（同样受上一行 2 年限制）；少交保费的，补交或按实交与应交的比例给付；多交的退还 | 《中华人民共和国保险法》第三十二条 |
| 指定受益人 | 由被保险人或投保人指定，投保人指定须经被保险人同意；单位给员工投保（团险）只能指定被保险人本人或其近亲属；可以指定多人并定顺序和份额，没定份额的按相等份额 | 《中华人民共和国保险法》第三十九条、第四十条 |
| 变更受益人 | 被保险人或投保人书面通知保险公司，保险公司在保单上批注或附贴批单；投保人变更须经被保险人同意 | 《中华人民共和国保险法》第四十一条 |
| 没有指定受益人 | 没有指定或指定不明、受益人先于被保险人死亡且没有其他受益人等情形，身故保险金作为被保险人的遗产，按继承办理 | 《中华人民共和国保险法》第四十二条 |
| 变更合同 | 投保人和保险公司协商变更，由保险公司在保单上批注、附贴批单，或双方订立书面变更协议 | 《中华人民共和国保险法》第二十条 |
| 保单转让与质押 | 以死亡为给付条件的保单，没有被保险人书面同意不得转让或质押 | 《中华人民共和国保险法》第三十四条 |
| 长期健康险犹豫期 | 长期健康保险必须设犹豫期，不少于 15 天，条款里写明犹豫期内的权利 | 《健康保险管理办法》（中国银保监会令 2019 年第 3 号）第十五条 |
| 犹豫期写在哪 | 一年期以上人身保险的产品说明书要写明犹豫期起算时间、天数、犹豫期内的权利，以及犹豫期后退保扣哪些费用、退保金怎么算 | 《一年期以上人身保险产品信息披露规则》（银保监规〔2022〕24号）第七条 |
| 转保提示 | 一年期以上人身险转保时，保险公司要让客户确认知道：退保或失效的利益损失；年龄、健康变化可能缩小新产品保障范围、提高费用；新产品的等待期、自杀和不可抗辩条款的起算时间可能重新计算 | 《人身保险产品信息披露管理办法》（中国银保监会令 2022 年第 8 号）第十五条 |

宽限期天数、复效条件、保单贷款、自动垫交、减保、减额交清，法律没有统一规定，以合同条款为准。

## 缴费与扣款

- **交费方式**：年交、月交、趸交（一次交清）。台账 `缴费方式` 照合同写；单位交的团险写「单位统一缴纳」。
- **扣款账户**：多数续期保费从投保时绑定的银行卡自动扣，以条款和投保单为准。换卡、销卡、卡里余额不够时，扣款失败不会有人上门催，先改绑或存钱。改绑在保险公司官方 App、客服电话或柜面办，办完保留回执。
- **扣款日**：一般是 `生效日 / 下次交费日` 里的第二个日期，提前几天开始扣、扣几次，看合同或保险公司通知。台账里的下次交费日每年交完后改成下一年的日期。
- **月交**：每个月都有一次扣款，一次失败就可能进入宽限期；月交保单的宽限期和年交可能不同，按条款写。
- **交完核对**：查扣款记录或保险公司的交费通知，确认交的是哪份保单、金额对不对；然后改台账 `下次交费日` 和 `缴费期` 里的「已交 __ 年」。
- **一年期保险的「续保」不是交续期保费**：一年期医疗险、意外险到期就是合同结束，要重新投保或按续保约定续上；有的产品设有续保宽限，有的没有，按条款写进 `续保或调整建议`。

## 宽限期

宽限期是交费日过后、还没交钱但保障仍在的那段日子。台账里对应两个字段：

| 台账字段 | 写法 | 用途 |
| --- | --- | --- |
| `生效日 / 下次交费日` | 两个日期，如 `2023-03-10 / 2027-03-10` | 第二个日期就是本期应交日 |
| `宽限期` | 按条款写天数，如 `60 天`、`30日` | 算宽限期止日 |

```
宽限期止日 = 下次交费日 + 宽限期天数
例：下次交费日 2027-03-10，宽限期 60 天 → 宽限期止日 2027-05-09
```

总览页「近 60 天待办」按这个算法列出宽限期止日（`references/15-总览页与加密.md`）。

写法规则：

- 条款「保险费的支付」「宽限期」一节写了天数，照写。
- 读过完整条款、确实没有写的，写「未识别」，不按 60 天填：法定的 60 日从约定交费期限起算，但保险公司催告过的是催告后 30 日，哪个先到要看催告日期。
- 还没拿到条款的，写「待补」，按 `references/03-保单台账与资料提取.md` 补资料。
- 宽限期写「未识别」或「待补」的保单，总览页不出宽限期止日，**把下次交费日当最后期限**。
- 宽限期内出险照赔，但会扣欠交的保费；不要把宽限期当成可以晚交的常规时间，交费日当天交上。
- 新保单收到时按 `templates/new-policy-check.md` 第四项把宽限期填好。

## 合同效力中止与复效

过了宽限期还没交，合同效力中止（有的合同约定改为自动垫交或减少保额，见下文「保单贷款与自动垫交」）。中止期间出险，保险公司不赔。

**复效**（恢复效力）：

1. 中止后尽早联系保险公司，问清复效条件：要补交的保费和利息、是否要重新做健康告知或体检、要交哪些材料。
2. 复效要保险公司同意，不是交了钱就自动恢复；健康变差的，可能被拒绝复效或要求加费。
3. 中止之日起满 2 年还没谈成的，保险公司有权解除合同、只退现金价值（第三十七条）。
4. 复效成功后，寿险的自杀免责 2 年从复效日重新算（第四十四条）；等待期、告知等是否重新计算，看条款，条款里找不到写「未识别」并问清。

**复效和重新投保比**：复效沿用原合同，费率按原投保年龄，原来的责任和除外不变；重新投保按现在的年龄和健康重新核保，等待期、2 年不可抗辩期和自杀免责期都从新合同成立起重算。复效时要补告知哪些、等待期是否重新计算，以条款和保险公司答复为准。

台账写法：合同中止时 `评估备注` 写「YYYY-MM-DD 起效力中止，复效截止 YYYY-MM-DD（中止日 + 2 年）」；TODO 加一条复效，写明截止日；矩阵里这份保单不再计入保额，按 `references/04-缺口矩阵.md` 重打档。复效后改回来，记 CHANGELOG。

## 续保与停售

| 保单类型 | 到期时怎么办 | 出处 |
| --- | --- | --- |
| 保证续保的医疗险 | 保证续保期内，前一期届满前申请续保，保险公司必须按原条款和约定费率承保 | 《健康保险管理办法》第四条 |
| 不保证续保的一年期医疗险、意外险 | 期满要重新申请，保险公司同意才有新合同；停售、理赔、健康变化都可能续不上 | 见 `references/19-理赔与报案.md`「理赔对续保的影响」 |
| 长期险（定期寿险、重疾险等） | 交费期内按时交费即可，不存在每年续保 | 以合同条款为准 |

- **停售**：保证续保的产品，停售后是否还能续，看条款「续保」一节怎么写；不保证续保的产品停售后，到期就不能再续。收到停售通知，台账 `续保或调整建议` 写「已停售，到期 YYYY-MM-DD 后不能续保」或照条款写能续到哪年。
- **停售后的换保**：按 `references/13-年度复盘与事件更新.md` 的换保顺序，新单先投、过了等待期，旧单再到期不续；TODO 硬期限段写明旧单 `保障到期日`。
- **保障到期日**：台账写具体日期，总览页「近 60 天待办」会列出；到期前一个月决定续、换还是停。

## 受益人与信息变更

**受益人**：

- 录台账时把 `受益人` 写清楚：每类保险金分别给谁（重疾、医疗保险金一般给被保险人本人，身故保险金给指定的人）；写的是「法定」就照写。
- 写「法定」或没写的，身故保险金按遗产处理，理赔要证明继承关系、全体继承人参与，材料最多、耗时最长（`references/19-理赔与报案.md`）。有明确想给的人，就去指定。
- 结婚、离婚、生孩子、受益人去世时，逐份查受益人，需要改的去改。
- **怎么改**：被保险人或投保人书面通知保险公司（官方 App、柜面或书面申请），投保人改受益人要被保险人同意；保险公司在保单上批注或出批单后才算改好，保存批单（第四十一条）。
- 团险的受益人由单位统一办理，只能是员工本人或其近亲属（第三十九条）；想指定的，问单位人事能否填写受益人指定书。
- 受益人写多人的，写清顺序和份额，否则按相等份额分。

**其他信息**：

| 变了什么 | 去保险公司改 | 库里改 |
| --- | --- | --- |
| 手机号、地址、邮箱 | 所有在保保单都改，否则收不到催告、停售、续保通知 | 不用改台账；客服电话变了改 `客服电话` |
| 扣款银行卡 | 改绑续期扣款账户 | 不写卡号；`评估备注` 记一行改绑日期 |
| 职业、工作地 | 条款要求职业变化通知保险公司的（意外险常见），按条款通知 | `members/<代号>.md` 职业；意外险台账 `评估备注` |
| 投保人（如父母换成子女） | 能否变更、要谁签字看条款，一般要原投保人、新投保人和被保险人都同意 | `投保人`；投保人豁免条款要重看（`references/09-投保人豁免.md`） |
| 发现年龄或告知写错 | 主动联系保险公司更正，按第三十二条、第十六条处理 | 台账 `评估备注` 记更正结果 |

所有改动以保险公司出的批单或变更确认为准，批单原件按 `references/14-隐私分级与资料原件.md` 存放，台账 `关联资料（文件名 / 位置）` 加一行。

## 保单贷款与自动垫交

只有有现金价值的保单（终身寿险、年金、两全、部分终身重疾）才可能有这两项；消费型医疗险、意外险、定期寿险通常没有。有没有、怎么算，全看条款。

- **保单贷款**：用保单的现金价值向保险公司借钱。条款里要看：可借上限（一般是现金价值扣欠款后的某个比例）、利率、每次借款期限、到期不还怎么办（多数是本息滚入下次借款；本息超过现金价值时合同效力中止；以条款为准）。借款期间出险，保险金会先扣掉未还本息。台账 `保单贷款上限与利率` 照条款写；借了款的，`评估备注` 写借款日、金额、还款日，TODO 加还款日。
- **向银行质押保单**：以死亡为给付条件的保单，要被保险人书面同意（第三十四条）。
- **自动垫交**：交费日过了宽限期还没交时，用现金价值自动垫付保费，合同继续有效。多数要投保时勾选或事后申请，以条款为准；垫交部分要计利息，现金价值不够垫时合同效力中止。条款里写了的，在台账 `减保 / 退保规则要点` 记「有自动垫交，已选 / 未选」。
- 这两项都是应急工具，不是理财；借款和垫交会让现金价值和保障一起缩水，能交上就正常交。

## 退保前核对

退保就是投保人解除合同，只拿回现金价值，保障立刻结束。过了犹豫期，想退保之前按下表逐项写清楚，写不清的不退：

| 核对项 | 怎么查 | 写进哪里 |
| --- | --- | --- |
| 现金价值 | 保单里的现金价值表，或问保险公司要当日退保金额；和已交保费比 | 台账 `当前现金价值` |
| 退保扣费 | 产品说明书「犹豫期后退保」一节（信息披露规则第七条要求写明） | `减保 / 退保规则要点` |
| 重新投保要重新核保 | 被保险人现在的健康状况，对照 `references/06-核保策略.md`；投保后新查出的病、体检异常都要告知 | 成员档案 |
| 新等待期 | 新保单等待期从新生效日重算（`references/12-等待期与犹豫期.md`） | 换保计划 |
| 2 年不可抗辩与自杀免责重算 | 新合同从成立日重新计算（保险法第十六条、第四十四条） | 换保计划 |
| 保障空窗 | 新单承保并过了等待期之前，旧单不能退 | TODO |
| 年龄上升 | 按现在的年龄投保，保费更高，有的已超过投保年龄上限 | 换保计划 |
| 有没有贷款、垫交 | 未还本息会从退保金里扣 | `评估备注` |
| 替代方案 | 减保（降低保额，保留部分保障）、减额交清（停交保费、保额按现金价值降低）、保单贷款应急，条款里有才能用 | `减保 / 退保规则要点` |

规则：

- **不为更好的产品退掉还在保障期内的旧单**；想加保障就另投一份（`references/05-配置原则.md`、`references/13-年度复盘与事件更新.md`）。
- 被保险人健康已经变差的（慢病、结节、手术后），旧单只续不退。
- 确实要退的（交不起、保额重复、形态选错且新单已承保），先投新单并确认承保、过了等待期，再退旧单。
- 退保前的决定写进 `<库目录>/决策记录.md`（`templates/decisions.md`）：日期、退或不退、理由、影响的规则。
- 退保后台账连同原件移到 `policies/<代号>/_ended/`，矩阵重打档，CHANGELOG 记一行。

## 犹豫期内核对清单

新保单签收后到犹豫期结束前，是退保能退回已交保费（合同约定的工本费除外）的唯一窗口。逐项做：

1. **算出犹豫期最后一天**：签收日 + 犹豫期天数（签收次日为第 1 天，见 `references/12-等待期与犹豫期.md`）。长期健康险不少于 15 天（见上文「法律与监管兜底的规则」）；其他产品有没有犹豫期、多少天，以合同条款和产品说明书为准。最后一天写进 TODO。
2. **按新保单五查逐项核对**：`templates/new-policy-check.md`（库里是 `新保单五查.md`）的健康告知、免责条款、等待期、续保条件、理赔流程，结果写进台账。
3. **核对保单信息**：投保人、被保险人、受益人、保额、保障期限、交费期、年保费、扣款账户和投保时说的一致；不一致的当场要求更正或退保重投。
4. **核对形态**：定期还是终身、保额够不够，对照推荐方案（`references/10-定期与终身.md`、`references/17-推荐方案输出.md`）。
5. **接回访电话**：长期险保险公司会在犹豫期内回访，按实际情况回答；回访时发现被误导的，可以明确提出解除合同。
6. **要退就在最后一天前书面申请**：保留申请回执。退的是要换的那份时，先确认新单已承保。
7. **过了犹豫期**：TODO 删掉这一条，台账补全，按 `references/13-年度复盘与事件更新.md`「新投保后立刻做的四步」更新矩阵和总览页。

## 家庭交接清单

库通常一个人维护。每年复盘时（`references/13-年度复盘与事件更新.md`「家庭应急交接」），和配偶或另一位家庭成员过一遍下面几项，确认对方知道：

| 对方需要知道 | 写法 |
| --- | --- |
| 保单和库在哪 | 原件存放位置（纸质柜子、电脑目录、云盘目录）；库目录在哪台电脑 |
| 总览页怎么打开、口令在哪 | 总览页文件位置；口令记在哪里（如家里的密码本，或密码管理器条目名；用了口令文件的，写明在 `.private/dashboard-passphrase`），不把口令本身写进交接卡 |
| 各保单续费方式和扣款日 | 每份保单：自动扣款还是手动交、扣哪个账户（只写银行名）、每年哪天扣；宽限期止日 |
| 出险后报案顺序 | 先查该成员全部保单，逐份报案；医疗费用先医保结算，再按顺序报其他保单；发票原件先给要原件的那家（`references/19-理赔与报案.md`） |
| 客服电话 | 每家保险公司一行；单位团险写单位人事联系人 |
| 本人做过哪些决定 | 指向 `决策记录.md`，例如哪些保单定了不退、受益人为什么这样指定 |

交接卡做成纸质或离线文件，不写证件号、完整保单号、银行卡号和口令；更新后旧卡销毁。维护者做出新的取舍时，当天记进 `决策记录.md`，不只留在聊天里。

## 示例

示例家庭爸爸的示例重疾 B（`examples/demo-family/policies/self/critical-shilirenshou-2023.md`）：年交 4,500 元，已交 4 年，下次交费日 2027-03-10，现金价值约 0.9 万元，甲状腺相关除外承保。

1. **宽限期**：翻条款「保险费的支付」，假设写的是 60 天，台账 `宽限期` 写 `60 天`，宽限期止日 = 2027-03-10 + 60 天 = 2027-05-09，总览页在 2027-03-10 前 60 天起列出交费日。
2. **扣款**：假设爸爸 2026 年换了工资卡，旧卡年底注销。在保险公司官方 App 把续期扣款改到新卡，`评估备注` 记「2026-12 改绑续期扣款账户」。爸爸的示例定寿 A（6 月交费）同一家公司，一起改。
3. **想退保换新的**：爸爸看到一款保额更高的重疾，想退掉重疾 B。按退保前核对：已交 1.8 万元，退保只拿回约 0.9 万元；爸爸有高血压 2 级和甲状腺结节，重新投保要重新告知，大概率仍除外甲状腺，可能还要因高血压加费或除外；新单重新等待 90 天；42 岁投保保费比 38 岁时高。结论：不退，结节复查稳定后另投一份把保额补到 50 万（与 `examples/demo-family/members/self.md` 备注一致）。这条写进 `决策记录.md`：`| 2026-11-21 | 示例重疾 B 不退保，另投补保额 | 退保损失约 0.9 万元，重新核保条件不会更好 | 退保前核对 |`。
4. **受益人**：定寿 A 和重疾 B 的身故受益人都是妈妈；单位团险身故受益人是「法定」。爸爸问单位人事能否把团险受益人指定为妈妈，能的话填指定书并保存回执，不能的话台账保持「法定」。
5. **交接**：复盘时和妈妈过一遍交接清单：保单原件在书房文件柜和 `.private/` 目录；总览页口令记在家里的密码本；重疾 B 每年 3 月、定寿 A 每年 6 月从爸爸新工资卡扣；爸爸出险先打示例人寿客服电话 400-000-0001，再联系单位人事报团险。

## 常见错误

| 错误 | 正确做法 |
| --- | --- |
| 换卡、销卡后忘了改续期扣款账户 | 换卡当天把所有保单的扣款账户一起改 |
| 条款没写宽限期，台账直接填 60 天 | 写「未识别」，把下次交费日当最后期限 |
| 把宽限期当成可以晚交的时间 | 交费日当天交；宽限期只是兜底 |
| 断交后直接重新投保 | 先问复效；复效沿用原合同，重新投保要重新核保、重算等待期 |
| 中止满 2 年才想起复效 | 中止当天在 TODO 写复效截止日 |
| 受益人一直写「法定」，结婚生子后也没查 | 家庭变化后逐份查受益人，想给谁就指定谁 |
| 只打电话说改受益人，没拿批单 | 书面申请，保存批单才算改好 |
| 为了更好的产品退掉已过犹豫期的长期险 | 另投一份；健康变差的旧单只续不退 |
| 先退旧单再投新单 | 新单承保并过了等待期，旧单再退 |
| 犹豫期最后一天不知道是哪天 | 签收当天算出最后一天写进 TODO |
| 只有维护者知道保单在哪、口令在哪 | 每年复盘时做家庭交接，决定记进 `决策记录.md` |
