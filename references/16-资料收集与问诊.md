# 16 资料收集与问诊

结论：首次建档按库里的 `资料收集清单.md`（来自 `templates/intake-checklist.md`）收资料；用户给什么先录什么，缺的项一次只问一个问题，问不到的写「待补」，不估不编。

## 资料清单

与 `templates/intake-checklist.md` 一致，分五组：

| 组 | 要什么 | 写进哪里 |
| --- | --- | --- |
| 家庭成员 | 人数与每人代号；每人出生年月；职业与职业类别（办公室 / 外勤 / 高危） | `members/<代号>.md` 基础信息 |
| 经济状况 | 家庭税后年收入与主要来源；房贷 / 车贷 / 经营负债的余额与剩余年限；可接受的年保费预算 | 成员档案经济状况（预算写在 `self`） |
| 健康 | 最近一次体检报告（结论页即可）；既往病史、住院与手术记录；吸烟饮酒、家族病史 | 成员档案健康状况，原件按 `references/14-隐私分级与资料原件.md` 存放 |
| 已有保障 | 社保 / 居民医保 / 单位团险；已有保单 PDF 或截图（首页、保障责任页、缴费页） | 成员档案已有保单，`policies/<代号>/` 台账 |
| 常见疑问 | 想先解决的问题；被推荐过、想核对的方案 | `TODO.md` 或下一次配置建议 |

## 收集顺序

1. **先问家庭结构**：几口人、各自代号与称呼、谁是主要收入来源。这决定建哪些成员档案（`node scripts/init-library.mjs <库目录> --members ...`）。
2. **再收已有保单**：让用户把能找到的保单 PDF、截图一次性给出，逐份按 `references/03-保单台账与资料提取.md` 录入。
3. **再收健康资料**：体检报告、病历、出院小结，逐人摘结论。
4. **最后问经济与预算**：收入、负债、预算。用户不愿意说具体数时，接受区间（如「年保费 1–2 万」）。
5. **出第一版矩阵**：资料不全也出，缺的格子标「缺资料」，并把缺项列进 TODO。不要等资料齐了才出。

## 从体检报告与病历提取

| 资料 | 摘什么 |
| --- | --- |
| 体检报告 | 体检日期；总检结论页列出的异常项（如「甲状腺结节 TI-RADS 3 类」「血脂偏高」）；身高体重；与核保相关的指标（血压、血糖、糖化血红蛋白、肝功能、结节分级） |
| 门诊病历 | 诊断名称、确诊日期、用药、是否需要复查 |
| 出院小结 | 入院与出院日期、出院诊断、手术或操作名称与次数、出院结论（治愈 / 好转）、出院医嘱（是否要求复查或补检查） |
| 核保结论通知 | 日期、险种、结论（标准体 / 加费 / 除外 / 延期 / 拒保）、除外或加费的具体内容 |

规则：

1. **写结论，不抄全文**：档案里写「2021 年急性阑尾炎手术，已痊愈」，报告全文作为原件另存。
2. **次数、日期、结论照原件**：手术做了两次就写两次；两份材料数字不一致时，和用户定一个以哪份为准，把这个决定写进 TODO 顶部「已定口径」。
3. **医嘱里的复查建议要记**：「建议复查」「建议完善检查」会被健康告知问到，即使用户决定不去查，也要记下来。
4. **医生口头提过、没写进病历的情况**：记在档案备注里，标明「口头提及，无书面记录」；是否需要在投保时告知，按具体产品的问题措辞判断（见 `references/06-核保策略.md`）。
5. **识别出的数字逐个核对**：图片文字识别后，日期、指标数值、分级与原图对照。

## 缺项补问

1. **一次只问一个问题**。不要一次列十个问题让用户填。先问最影响结论的：主要收入者的收入与负债 → 各成员已有保单 → 健康异常 → 预算 → 其他。
2. **问题要具体、可直接回答**：问「妈妈最近一次体检是哪一年，有没有写结节、血糖、血压方面的异常？」，不问「妈妈健康怎么样？」。
3. **给出回答方式**：可以说「不知道」「先跳过」，也可以拍照、截图或口述。
4. **问不到的写「待补」**：用户说不知道或暂时不想给，档案或台账写「待补」或「资料未取得」，TODO 加一条，写明去哪里补（保司 App、支付平台保单页、单位人事、学校、当地社保）。不估、不按同龄人平均值填。
5. **记住已答过的**：用户答过的写进库，下次不再问；用户拍板的口径写进 TODO 顶部「已定口径」。
6. **疑问单独记**：用户提出的问题（「孩子要不要买」「老人还能买什么」「这个方案划不划算」）记进 TODO，等矩阵出来后在配置建议里回答。

## 示例

示例家庭的收集结果：

- 家庭结构：六口人，`self` 爸爸是主要收入来源，`spouse` 妈妈自由职业，`son` 哥哥、`daughter` 妹妹、`father` 外公、`mother` 外婆。
- 已有保单 12 份，按被保人分到 `examples/demo-family/policies/` 下六个目录。
- 健康：爸爸的体检报告与病历摘成「高血压 2 级，2022 年确诊，两种降压药控制，近半年血压约 135/85 mmHg；甲状腺结节 TI-RADS 3 类，每年复查超声，大小稳定」；哥哥的出院记录摘成「2021 年急性阑尾炎手术，已痊愈」。
- 没问到的：外婆的养老金、爸爸的企业年金、哥哥学校统一投保的学平险额度。档案写「资料未取得」，矩阵对应格是「缺资料」，`examples/demo-family/TODO.md` 各列一条并写明去单位人事、当地社保、学校取。

补问示例（一次一个）：

> 爸爸的房贷现在还剩多少，还要还几年？不确定的话给个大概区间也可以。

用户回答「200 万，25 年」后写进 `members/self.md`，再问下一个：

> 外公的老年意外险保额是多少？保单首页或保障责任页拍一张给我就行。

## 常见错误

| 错误 | 正确做法 |
| --- | --- |
| 一次抛出十几个问题 | 一次一个，按影响大小排序 |
| 资料不全就不出矩阵 | 先出，缺的标「缺资料」 |
| 用户没说的收入、保额按常见值估 | 写「待补」，TODO 列补资料 |
| 只摘体检报告的异常，不记复查建议 | 医嘱里的复查与补检建议也要记 |
| 手术次数、日期写得含糊 | 照出院小结原文写 |
| 已经回答过的问题又问一遍 | 先读库，答过的不再问 |
