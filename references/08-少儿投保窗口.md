# 08 少儿投保窗口

结论：孩子的长期险（重疾、长期医疗）在 0 岁投保时健康告知最简单、费率最低；窗口的上界是满周岁前一天，下界是产品最早可投日龄与病史痊愈满 N 个月两者中较晚的一天，实际投保日再往前留 2–4 周缓冲。

## 判断规则

### 为什么是 0 岁

- 少儿重疾按投保年龄定费率，0 岁最便宜，保费锁定后整个交费期不变。
- 婴儿的病史最少，健康告知最容易全答「否」。年龄越大，住院、手术、过敏、发育问题越可能出现在告知里。
- 投保年龄按周岁算：满周岁当天起就是 1 岁，费率跳档。

### 上界：硬线与缓冲

1. **硬线 = 满周岁前一天**。出生日 2026-07-15 的孩子，硬线是 2027-07-14。
2. **看生效日**：多数产品次日零时生效；条款按生效时年龄计费的，生效日也必须在硬线之前，即最晚在满周岁前两天投保。
3. **留缓冲 2–4 周**：智能核保要试几家、可能需要换产品、扣款可能失败、证件或医保信息可能要补。实际计划投保日 = 硬线往前 2–4 周。
4. 硬线和计划日都写进 TODO 最上面「错过不可逆」一段（`references/01-建库与日常维护.md`）。

### 已进入缓冲期

今天离硬线已不足 2–4 周（计划投保日已过、硬线还没到）时，先判断赶不赶：

1. **列出剩下要做的事**：选定产品、智能核保、补告知材料（出院小结、医保信息）、首期扣款；按生效时年龄计费的，生效日还要落在硬线之前。
2. **能赶就赶**：产品已选定、健康告知能全答「否」或智能核保能当场出结论、材料齐的，在硬线前至少留出 2–3 天给扣款和生效，当天投。
3. **不硬赶**：要转人工核保、材料还缺、要在几款产品间重新比较的，人工核保要几天还是几周以保险公司答复为准，赶不上就不赶，不为了赶线在告知上含糊。
4. **赶不上的退路**：
   - 按下一年龄的费率投：投保页分别试算 0 岁和 1 岁的年保费，差额 × 交费年数就是多付的钱，写进推荐方案，和用户确认后投。
   - 家里正在投或已有长期医疗家庭单的，问保险公司能否把孩子并入家庭单，能并的按条款的投保年龄和费率办。
5. **落地**：赶的，TODO 最上面写「YYYY-MM-DD 前投保，硬线 YYYY-MM-DD」；不赶的，把改按下一年龄投保的决定和理由记进 `决策记录.md`，TODO 改成新的计划投保日。

### 下界：日龄与病史

1. **最早可投日龄**：多数少儿重疾、医疗要求出生满 28 天或满 30 天，以条款为准。
2. **病史痊愈满 N 个月**：孩子住过院或做过手术时，很多产品要求痊愈（出院诊断治愈）满 N 个月才按标准体承保，不足则延期。N 常见 3、6、12 个月，以具体产品问卷为准。起算日用出院小结上的出院日期。
3. **下界 = 两者中较晚的一天**。

### 窗口怎么用

- 实际窗口 = 下界到计划投保日。窗口短时，选品、比价、核保预案、出院小结等告知材料都要在下界之前备齐，窗口一开就投。
- 事先定好核保结论不理想时投不投：接受哪些除外照投、加费多少以内接受、只接受标准体否则放弃。窗口里没有反复讨论的时间。
- **下界晚于硬线时，窗口已经没有**：换一款对病史要求更宽（如满 3 个月）的产品；仍不行，就接受 1 岁费率，等病史满期后再投。不为了赶窗口在告知上含糊（`references/06-核保策略.md`）。
- 意外险不看健康，与窗口无关，随时可投。
- 居民医保尽早参保，商业医疗险在医保生效后投，报销顺序才对。

### 其他年龄窗口

同样的算法（硬线 = 跨档或上限前一天，下界 = 可投条件满足日，留缓冲）适用于：

- 10 周岁、18 周岁：未成年人身故保险金合计上限从 20 万变 50 万、再到不受该限制（`references/04-缺口矩阵.md` 意外阈值）。
- 老人投保年龄上限：防癌医疗、老年意外常卡 60、65、70 周岁。
- 成人每过一个生日费率上调一档，40 岁以后上调幅度变大。

## 示例

示例家庭的妹妹（`examples/demo-family/members/daughter.md`）2026-07 出生，足月顺产，满月体检正常。按出生日 2026-07-15 算：

```
硬线：满周岁前一天                 2027-07-14
最早可投：出生满 28 天              2026-08-12
病史下界：无住院、手术               不适用
下界：                             2026-08-12
计划投保：满月体检后                 2026-08 下旬
```

少儿重疾在 2026-08 下旬投保，2026-09-01 生效（`examples/demo-family/policies/daughter/critical-shilirenshou-2026.md`），离硬线还有 10 个多月，没有赶工。

假如妹妹 2026-12-10 因急性肠胃炎住院出院、诊断治愈，所选产品要求出院满 3 个月：病史下界变成 2027-03-10；硬线 2027-07-14 往前留 4 周，计划投保日 2027-06-16；实际窗口是 2027-03-10 至 2027-06-16。

哥哥 10 岁，0 岁窗口早已过去；2021 年阑尾炎手术已痊愈，问卷问「是否做过手术」时照实答，不影响少儿重疾承保。

## 常见错误

| 错误 | 正确做法 |
| --- | --- |
| 以为满周岁当天还能按 0 岁投 | 硬线是满周岁前一天，按生效日计费的再提前一天 |
| 卡着硬线最后一天投 | 留 2–4 周缓冲给核保和换产品 |
| 进了缓冲期、要人工核保还硬赶 | 赶不上就按下一年龄费率投，或问能否并入家庭单 |
| 只看日龄，忘了病史满期要求 | 下界取日龄和病史满 N 个月中较晚的一天 |
| 病史没满期就在告知里含糊带过 | 换要求更宽的产品，或接受 1 岁费率 |
| 窗口开了才开始选品 | 选品、核保预案、告知材料在下界前备齐 |
| 为了 0 岁窗口挤掉支柱寿险的预算 | 孩子选定期形态（`references/10-定期与终身.md`） |
