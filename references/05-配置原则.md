# 05 配置原则

结论：先保经济支柱，再保孩子，最后保老人；同一层里先补错过就不可逆、无健康告知、便宜的项；预算不够时按三档从后往前砍，不砍支柱的寿险和全家的医疗险。

## 判断规则

### 先后顺序

1. **经济支柱**：家庭主要收入来源，以及有收入、共同承担房贷的人。支柱倒下，家庭失去现金流和还贷能力，是「破产」级风险；孩子或老人生病，有医保和医疗险兜底，是「难过」级风险。
2. **孩子**：重疾、医疗、意外。孩子保费便宜，但不能为了孩子挤掉支柱的寿险。
3. **老人**：医疗（防癌医疗、惠民保）、意外。55 岁以上新配重疾常常保费倒挂，用防癌医疗替代（见 `references/04-缺口矩阵.md` 重疾阈值）。

支柱内部按要紧程度排：寿险 → 医疗 → 重疾 → 意外。主要收入者寿险为 0 时，它固定是全家第一优先，排在任何孩子和老人的缺口前面。

这个顺序和下面的预算分档不矛盾：分档按「要紧程度 + 保费高低」划。意外险排在最后，但它几百元、不看健康，可以和寿险、医疗同时办，所以放进第一档；重疾比意外要紧，但保费是几千元一档，所以「补到 50 万」放第二档——预算紧时现有重疾保额保留不动，只是暂缓加保。

### 同一层里谁先

按下面四条依次比较，先满足的排前：

1. **硬期限**：满周岁费率窗口（`references/08-少儿投保窗口.md`）、投保年龄上限（防癌医疗、老年意外常卡 60、65、70 周岁）、年龄跨档涨价、惠民保年度参保截止日。错过不可逆的永远排第一。
2. **无健康告知**：意外险、惠民保不看健康，今天就能投，不等任何前置。资料没收齐时，这两项也可以先给建议、标「资料待补」；需核保、保费高的项先补资料（`references/17-推荐方案输出.md`）。
3. **保费低、缺口大**：几百元补上一个「不足」，先于几千元把「一般」抬到「充分」。
4. **越晚越难核保**：健康状况可能变差的人（有结节、指标偏高、正在复查），趁现在能过告知先投。

### 预算分档

全家年保费常见在家庭税后年收入的 5%–10%；超过 10% 时要和用户确认，或按下表从第三档往前砍。

- **收入口径**：家庭税后年收入，即有收入的家庭成员到手收入合计。用户只给了税前收入或只知道一方收入时，先用已知数算，写明「按税前」或「只含一方收入」；成员档案里收入写税前还是税后要标清楚。
- **保费口径**：只算人身险（寿险、重疾、医疗、意外、年金、惠民保）的年保费。车险、家财险等财产险不计入这个预算，也不计入比例；月交保费按 12 个月折成年保费。

| 档 | 内容 | 说明 |
| --- | --- | --- |
| 第一档（必须） | 支柱定期寿险；全员医疗险（百万医疗 / 长期医疗，核保受限的用防癌医疗）；成人与老人意外险；全员惠民保 | 便宜、杠杆高，缺了会让家庭破产 |
| 第二档（视预算） | 重疾补到每人 50 万；非主要收入一方的定期寿险补足 | 收入损失补偿，保费比第一档高 |
| 第三档（有余力） | 重疾选终身形态；年金、教育金、增额寿 | 储蓄或长期锁定，不是保障缺口 |

### 配置与换保的固定口径

- **支柱寿险为 0 或不足时，孩子的重疾选定期形态**，把定期与终身的保费差留给支柱寿险（`references/10-定期与终身.md`）。
- **健康的成员趁健康换长期医疗**（保证续保 15–20 年）；有既往症的成员，现有医疗险只续不退，另加防癌医疗兜底。
- **到期切换，不中途退保**：新保单先投、过了等待期，旧保单再到期不续，允许重叠一个月（`references/12-等待期与犹豫期.md`）。
- **能年交就不月交**：月交绑定的银行卡过期或余额不足会静默断保，没人通知。确实要月交的，把扣费日写进 TODO「年度提醒」。
- **意外险的身故保额不替代寿险**：意外只赔意外，疾病身故不赔，支柱的身故缺口由定期寿险补。

## 示例

示例家庭（`examples/demo-family/`）家庭税后年收入 45 万，年保费预算 4 万以内：

- 第一优先是爸爸寿险：主要收入来源，应保额 362 万，现有 200 万只覆盖 55%（算法见 `references/04-缺口矩阵.md`）。其次是爸爸医疗：百万医疗被拒，先补防癌医疗。
- 妈妈有收入、共同承担房贷，按支柱层处理，补 100 万定期寿险，保至 65 岁（房贷在她 65 岁时还清）。
- 外婆的老年意外排在孩子的部分缺口前面：无健康告知、几百元、现在就能投，而且外婆骨质疏松，跌倒骨折风险高。
- 妹妹的重疾在 0 岁窗口内投了定期 30 年，没有选终身：爸爸寿险还差 162 万，钱先给爸爸。
- 配置建议新增约 0.9–1.4 万，全家年保费约 2.8–3.3 万，约占税后收入 6%–7%，在第一、二档之内，不动第三档（`examples/demo-family/recommendations/2026-11-20.md`）。

## 常见错误

| 错误 | 正确做法 |
| --- | --- |
| 先给孩子买贵的终身重疾，大人寿险为 0 | 先补支柱寿险，孩子选定期 |
| 先买年金、增额寿，保障缺口没补 | 保障缺口补完再考虑第三档 |
| 拿意外险身故保额当寿险 | 疾病身故不赔，寿险单独补 |
| 为了换「更好的产品」先退掉在保的旧单 | 新单过等待期后旧单到期不续 |
| 有既往症的成员也退掉旧医疗险换新 | 只续不退，新产品大概率被既往症卡住 |
| 预算超了就平均砍每个人的保额 | 按三档从后往前砍，第一档不动 |
| 把车险保费算进人身险预算 | 财产险单列，不计入占比 |
| 拿税前收入算占比不标注 | 用家庭税后年收入；只有税前数时写明「按税前」 |
| 忽略年龄上限，拖到老人过了投保年龄 | 硬期限排在同层第一位 |
