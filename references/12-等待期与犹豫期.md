# 12 等待期与犹豫期

结论：等待期从保单生效日起算，期内因疾病出险不赔，是保险公司防带病投保的期限；犹豫期从签收保单的次日起算，期内退保退回全部保费，是给投保人反悔的期限；两者起点和作用都不同，换保时先投新单、过了等待期再停旧单。

## 判断规则

### 等待期

- **起算**：合同生效日，一般是投保次日零时。条款常写「自本合同生效之日起 N 日内」，含生效日当天。
- **期内出险**：因疾病确诊或住院，多数不赔，退还已交保费并终止合同，或者该疾病以后都不赔，看条款。意外导致的出险不受等待期限制。
- **常见长度**：

  | 险种 | 常见等待期 |
  | --- | --- |
  | 百万医疗 / 长期医疗 | 30 天，特定疾病 90 天 |
  | 防癌医疗 | 90 天 |
  | 重疾险 | 90 天或 180 天 |
  | 定期寿险 | 90 天或 180 天（只限疾病身故） |
  | 意外险 | 无 |
  | 惠民保 | 多为无或很短，看当年条款 |

- **续保不再有等待期**：同一产品按时续保，不重新计算。断交过宽限期后重新投保，等待期从头算。
- **台账里记生效日和等待期结束日**（`references/03-保单台账与资料提取.md`）。

### 犹豫期

- **起算**：投保人签收保险合同（电子保单以送达或签收日为准）的次日起。
- **长度**：一年期以上的人身险不少于 15 天，很多产品 20 天。一年期短险（百万医疗、意外险）多数没有犹豫期，退保按未满期保费退。
- **期内退保**：退还全部已交保费，部分产品扣不超过 10 元工本费。
- **期后退保**：只退现金价值。定期寿险、消费型重疾的现金价值很少或为零；储蓄型产品前几年的现金价值远低于已交保费。
- **用途**：发现形态、保额、投保人或受益人选错时修正（`references/10-定期与终身.md`）。先确认新单承保，再在犹豫期内退旧单。

### 换保时两者怎么配合

1. 新单先投并承保，记下生效日和等待期结束日。
2. 新单等待期内，旧单继续有效，不退不停。
3. 等待期过后，旧单到期不续；旧单是长期险的，再判断是否退保（已过犹豫期的长期险一般不退，见 `references/05-配置原则.md`）。
4. 有既往症的成员，新单可能除外，旧单只续不退。

### 计算写法

```
等待期结束日 = 生效日 + N − 1 天（含生效日的写法）
等待期后首日 = 生效日 + N 天
犹豫期最后一天 = 签收日 + 犹豫期天数（签收次日为第 1 天）
```

## 示例

示例家庭妹妹的少儿重疾（`examples/demo-family/policies/daughter/critical-shilirenshou-2026.md`）：生效日 2026-09-01，等待期 90 天。

```
2026-09-01 生效（第 1 天）
9 月 30 天 + 10 月 31 天 + 11 月 29 天 = 90 天
等待期结束日：2026-11-29
2026-11-30 起确诊合同约定疾病才赔
```

假设电子保单 2026-08-28 送达签收，犹豫期 15 天：08-29 为第 1 天，最后一天是 2026-09-12，在此之前改主意可以全额退保。

妹妹居民医保生效后投少儿医疗：等待期 30 天，这 30 天内生病住院不赔，所以医疗险不要拖到孩子已经生病时才投。

爸爸新投防癌医疗后有 90 天等待期，这期间仍靠单位补充医疗和惠民保；所以防癌医疗要趁在职时投，不要等离职、单位补充医疗失效后再投。

## 常见错误

| 错误 | 正确做法 |
| --- | --- |
| 把等待期和犹豫期当成一回事 | 等待期管赔不赔，犹豫期管能不能全额退 |
| 等待期从投保日或签收日算 | 从生效日算，看条款含不含当天 |
| 换保时先退旧单再投新单 | 新单过等待期后旧单再停 |
| 以为续保要重新过等待期 | 按时续保不重算；断保重投才重算 |
| 过了犹豫期退长期险换「更好的」 | 现金价值很低，不退，另加 |
| 一年期医疗险也等犹豫期退保 | 短险多数无犹豫期，按未满期保费退 |
