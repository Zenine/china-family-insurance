# 资料收集清单

首次建档按这张清单准备。原件（证件、病历、体检报告、保单 PDF）随库保存在私有目录（库可能公开或同步到别处时只放 `.private/`），台账正文只写结论与文件名。

## 家庭成员
- [ ] 家庭人数与每人代号（self / spouse / daughter / son / father / mother …）
- [ ] 每人年龄（出生年月）
- [ ] 每人职业与职业类别（办公室 / 外勤 / 高危）

## 经济状况
- [ ] 家庭年收入（税后）与主要收入来源
- [ ] 负债：房贷 / 车贷 / 经营负债的余额与剩余年限
- [ ] 可接受的年保费预算

## 健康
- [ ] 最近一次体检报告（结论页即可）
- [ ] 既往病史、住院与手术记录
- [ ] 吸烟 / 饮酒情况、家族病史

## 已有保障
- [ ] 社保 / 居民医保 / 单位团险
- [ ] 已有保单 PDF 或截图（保单首页、保障责任页、缴费页）

## 常见疑问
- [ ] 想先解决的问题（例如：主要收入者出事怎么办、孩子要不要买、老人还能买什么）
- [ ] 已经被推荐过、想核对的方案
